Задание 25 — это программирование, а не ручной счёт. Нужно перебрать числа на отрезке или кандидатов по маске, разложить число на множители, посчитать делители и выбрать те, что удовлетворяют условию. В базе Kompege по теме 1 075 задач, 124 решения (119 программных и 5 текстовых) и 241 видеоразбор (144 YouTube, 63 VK, 34 Rutube). Около 490 формулировок связаны с делителями, 462 — с масками, а 102 задачи совмещают оба условия.

Число и его делители

Делитель натурального числа N — такое натуральное d, при котором N делится на d без остатка. У каждого делителя есть пара N/d, поэтому все делители удобно искать до √N: если d ≤ √N делит N, то N/d — второй делитель пары. Единица и само N тоже являются делителями, но во многих формулировках их просят не учитывать.

  • Если d делит N, то и N // d делит N: делители идут парами.
  • При переборе d от 2 до isqrt(N) добавляйте оба числа: d и N // d.
  • Если d = N // d, делитель один: это полный квадрат, не добавляйте его дважды.
  • «Нетривиальные» делители — все, кроме 1 и N; «собственные» — все, кроме N.
  • Простые числа имеют ровно два делителя: 1 и само число.
  • Ноль не является делителем натурального числа.
d | N ⇔ N % d == 0N = d · (N // d)d ≤ √N ⇔ N // d ≥ √N

Простые числа и разложение

Простое число делится только на 1 и на себя. Единица не является ни простой, ни составной. Любое N > 1 единственным образом раскладывается на простые множители: N = p1^a1 · p2^a2 · … · pk^ak. Это разложение — ключ к задачам, где делители нельзя перечислить вручную.

  • Проверка простоты — перебор d от 2 до isqrt(N); найденный делитель означает составное число.
  • 2 — единственное чётное простое; после проверки 2 можно идти только по нечётным d.
  • Для разложения делите N на p, пока оно делится; так в словаре останутся степени.
  • «Различные простые делители» — ключи разложения; с кратностью — с повторами.
  • Для сотен тысяч чисел решето Эратосфена быстрее проверки каждого числа отдельно.
  • Оставшееся число больше 1 после trial division — простое, его тоже нужно добавить.
N = p1^a1 · p2^a2 · … · pk^akпростое число: ровно 2 делителя1 — не простое и не составное

Сколько делителей у числа

Если N = p1^a1 · p2^a2 · … · pk^ak, то количество всех натуральных делителей τ(N) = (a1+1)(a2+1)…(ak+1). Множитель (ai+1) — число способов выбрать степень pi от 0 до ai. Формула незаменима, когда N огромно или когда известно только разложение.

  • τ(360) = τ(2^3 · 3^2 · 5) = 4 · 3 · 2 = 24.
  • Количество нетривиальных делителей = τ(N) − 2.
  • τ(N) нечётно тогда и только тогда, когда N — полный квадрат.
  • Если N = 2^a · m и m нечётно, чётных делителей ровно a · τ(m), нечётных — τ(m).
  • Ровно три чётных делителя, считая само N: N = 8 или N = 2p².
  • Если N не считать, ровно три чётных делителя дают N = 16, 4p, 2p³ или 2pq (p и q — различные нечётные простые).
  • Ровно пять различных нечётных делителей: нечётная часть N имеет вид p⁴.
τ(N) = (a1+1)(a2+1)…(ak+1)чётных делителей: a · τ(m), где N = 2^a · mнечётных делителей: τ(m)τ(N) нечётно ⇔ N — полный квадрат

Сумма делителей

Сумма всех делителей σ(N) также выражается через разложение: σ(N) = ∏ (p^(a+1) − 1)/(p − 1). Чтобы получить сумму без 1 и самого N, вычтите 1 и N. Для суммы только простых делителей используйте ключи разложения, а не все делители.

  • σ(360) = 15 · 13 · 6 = 1170; сумма без 1 и 360 равна 809.
  • Сумма простых делителей без кратности — сумма ключей разложения.
  • Сумма простых делителей с кратностью — сумма p · a по всем p.
  • Если N = 2^a · m, сумма чётных делителей равна (2 + 4 + … + 2^a) · σ(m).
  • Сумма нечётных делителей — это σ(m), где m — нечётная часть N.
  • σ(N) нечётна тогда и только тогда, когда N — квадрат или удвоенный квадрат.
σ(N) = ∏ (p^(a+1) − 1)/(p − 1)сумма без 1 и N: σ(N) − 1 − Nσ(N) нечётна ⇔ N = t² или N = 2t²

Парные делители и позиции

Делители идут парами d и N/d. Поэтому наименьший нетривиальный делитель — первый найденный d > 1, а наибольший собственный делитель — N / d_min для составного N. Пятый по величине делитель — это N, делённое на пятый по возрастанию нетривиальный делитель.

  • Наибольший делитель, не равный N, равен N // d_min, где d_min — наименьший простой делитель.
  • k-й по величине нетривиальный делитель = N // (k-й по возрастанию нетривиальный).
  • Минимальный и максимальный нетривиальные делители: d_min и N // d_min.
  • Сумма пары равна d + N/d; пара ближе к √N, когда d ближе к корню.
  • «Пятый по величине» проще искать, собрав и отсортировав делители; при огромном N — через пять наименьших.
  • Для простого числа нетривиальных делителей нет, поэтому M(N) = 0 по условию.
d · (N // d) = Nmax_proper = N // min_divisor_>1k-й_max = N // (k-й_min)

Чётность и особые свойства

Многие условия читаются через строение числа, а не через полный перебор. Чётность количества делителей, нечётность суммы, произведение делителей и точное число делителей — всё это признаки, которые проверяются по разложению.

  • Все делители нечётны тогда и только тогда, когда N нечётно.
  • Сумма всех делителей нечётна тогда и только тогда, когда N — квадрат или удвоенный квадрат.
  • Произведение всех делителей равно N^(τ(N)/2); для полного квадрата это (√N)^τ(N).
  • Если сумма и произведение делителей нечётны, N — нечётный квадрат.
  • Ровно 4 делителя: N = p³ или N = p · q (p ≠ q).
  • Ровно 6 делителей: N = p⁵ или N = p² · q.
  • Ровно 9 делителей: N = p⁸ или N = p² · q².
τ = 4: p³ или p · qτ = 6: p⁵ или p² · qτ = 9: p⁸ или p² · q²произведение делителей = N^(τ/2)

Цифры, окончания и остатки

В задании 25 часто комбинируют делители с десятичной записью: делитель оканчивается на 7, сумма цифр кратна 14, число является палиндромом. Сначала выделите дешёвое цифровое условие, затем проверяйте делители.

  • Последняя цифра: n % 10; две последние: n % 100; три последние: n % 1000.
  • Сумма цифр: sum(map(int, str(n))); произведение считайте отдельно, ноль — особый случай.
  • Палиндром: s == s[::-1].
  • «Делитель оканчивается на d» — это d % 10 == digit, а не N % 10.
  • «Делитель двузначный» — 10 ≤ d ≤ 99; «трёхзначный» — 100 ≤ d ≤ 999.
  • Остаток от деления суммы делителей: сначала сумма, затем % m.
last = n % 10digits = [int(c) for c in str(n)]palindrome: s == s[::-1]

Маски «?» и «*»

Маска — это строка из цифр и символов «?» и «*». «?» заменяет ровно одну цифру, «*» — любую последовательность цифр, в том числе пустую. В Python маску проверяет fnmatch.fnmatchcase. Маска задаёт не число, а его десятичную запись, поэтому важна длина и то, что у числа нет ведущих нулей.

  • fnmatchcase(str(x), '12*4?5') истинно, если вся запись x подходит под маску.
  • «*» может соответствовать пустой строке; «?» — ровно один символ.
  • Если маска начинается с «?», первая цифра числа всё равно не может быть нулём.
  • Для делимости на m перебирайте не все числа, а кратные: range(m, limit + 1, m).
  • Маска без «*» задаёт точную длину; с «*» длина переменная.
  • fnmatch трактует квадратные скобки как класс символов; в экзаменационных масках их нет.
from fnmatch import fnmatchcaserange(m, limit + 1, m)«?» = 1 цифра, «*» = 0 или больше цифр

Стратегия и сложность

Главная ошибка — перебирать слишком широкий диапазон с полной проверкой делителей. Сначала оцените количество чисел и стоимость проверки. Если чисел несколько тысяч, прямой перебор с √N обычно успевает; если чисел 10⁵ и больше, даже проверка до корня может занять минуты — ищите строение числа, маску или кратные.

  • Стоимость прямой проверки: длина диапазона × √N. Для 10⁵ чисел около 10⁹ операций — уже медленно.
  • Для 10⁷–10⁸ чисел используйте решето или проверяйте только кратных и кандидатов.
  • math.isqrt(N) точнее и быстрее, чем int(N ** 0.5) на больших числах.
  • Проверяйте дешёвые условия (маска, последняя цифра, чётность) раньше перебора делителей.
  • При «первых N» ставьте break сразу после N-го найденного; при «последних N» идите вниз.
  • Если ответ не находится, увеличивайте лимит постепенно и проверяйте границы.
O(len · √N) — прямой переборрешето: O(n log log n), память O(n)isqrt(N) вместо N ** 0.5

Формат ответа

В задании 25 ответ — не одно число, а таблица пар или несколько значений. Формулировка всегда уточняет порядок: по возрастанию числа, по возрастанию делителей, сначала N, затем делитель или наоборот. Перечитайте её перед записью.

  • «Запишите само число и …» — сначала N; «справа от числа» — N, затем значение.
  • «Два наибольших делителя в порядке возрастания» — меньший, затем больший.
  • «В порядке убывания» — начинайте с большего и не сортируйте по возрастанию по привычке.
  • «Частное от деления» — это x // d, а не сам делитель.
  • «Количество подходящих чисел» — одно число, а не список.
  • Границы: [a; b] включает b; «больше a» начинается с a+1; «меньше b» заканчивается b−1.
  • Лишние строки таблицы в бланке не заполняйте.
[a; b] → range(a, b + 1)x > a → range(a + 1, …)x < b → range(…, b)

01

Делители до корня: базовый перебор

Когда использовать: Задан небольшой отрезок, и каждое число нужно проверить полностью: найти все делители, их количество, сумму, минимальный или максимальный делитель.

  1. Запишите границы отрезка и проверьте, включён ли правый конец.
  2. Для каждого N заведите множество делителей и добавьте 1 и N.
  3. Переберите d от 2 до isqrt(N); если d делит N, добавьте d и N // d.
  4. Отсортируйте делители и примените условие задачи.
  5. Напечатайте N и требуемые делители в указанном порядке.
  • Множество убирает повтор, когда d = N // d (полный квадрат).
  • Если нужны только количество и сумма, список можно не хранить, но с множеством проще не ошибиться.
  • «Ровно k делителей» — это len(ds) == k; «ровно k нетривиальных» — len(ds) - 2 == k.
  • Два наибольших делителя — ds[-1] и ds[-2]; если N исключён, берите ds[-2] и ds[-3] и выводите их по возрастанию.
  • Перебор до isqrt(N), а не до N // 2 — главное ускорение.

Пример

На отрезке [110; 120] найдите числа с ровно четырьмя делителями и выведите два наибольших делителя, не равных N, в порядке возрастания.

from math import isqrt

def divisors(n):
    ds = {1, n}
    for d in range(2, isqrt(n) + 1):
        if n % d == 0:
            ds.add(d)
            ds.add(n // d)
    return sorted(ds)

for n in range(110, 121):
    ds = divisors(n)
    if len(ds) == 4:
        print(n, ds[1], ds[2])

02

простые числа и простые делители

Простые числа: проверка и решето

Когда использовать: Нужно найти простые числа на отрезке, разложить число или получить его простые делители — с кратностью или без.

  1. Для одного числа проверяйте d от 2 до isqrt(N); для 2 и чётных случаев сделайте отдельные ветки.
  2. Для разложения делите N на найденный p, пока оно делится, и запоминайте степень.
  3. Для большого отрезка постройте решето Эратосфена и проверяйте простоту по массиву.
  4. Для суммы или количества простых после решета постройте префиксные суммы.
  5. Не забудьте добавить остаток N > 1 в разложение.
  • 1 не является простым; 2 — простое и единственное чётное простое.
  • Проверять делители достаточно до isqrt(N).
  • «Простые делители» — не все делители: у 12 это 2 и 3.
  • Для различных простых делителей делите N на p полностью; для кратности сохраняйте показатель.
  • Решето выгодно при n ≥ 10⁵–10⁶; для нескольких больших чисел — trial division.

Пример

Найдите все простые числа на отрезке [110; 130] и выведите их с порядковыми номерами.

from math import isqrt

def is_prime(n):
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    for d in range(3, isqrt(n) + 1, 2):
        if n % d == 0:
            return False
    return True

k = 0
for n in range(110, 131):
    if is_prime(n):
        k += 1
        print(k, n)

03

Формулы τ(N) и σ(N): когда делители не перечислить

Когда использовать: N большое или известно разложение, а нужны количество или сумма делителей; либо нужно найти число с заданным числом делителей.

  1. Разложите N на простые множители.
  2. Для количества делителей перемножьте (ai + 1).
  3. Для суммы делителей используйте сумму геометрической прогрессии по каждому p.
  4. Для поиска числа с заданным τ переберите разбиения τ на множители (ai + 1).
  5. Сопоставьте большие показатели меньшим простым числам и проверьте ограничение.
  • τ(360) = 24, σ(360) = 1170; сумма без 1 и N равна 809.
  • 117 = 9 · 13 — один из вариантов: показатели 8 и 12 дают p⁸q¹².
  • 1000 = 5 · 5 · 5 · 2 · 2 · 2; минимальное число 2⁴ · 3⁴ · 5⁴ · 7 · 11 · 13 = 810 810 000.
  • 39 = 3 · 13: подходят p³⁸ и p²q¹².
  • Для полного квадрата все показатели чётны, поэтому τ нечётно.
  • Сумма без 1 и N: σ(N) - 1 - N.

Пример

Найдите количество и сумму всех натуральных делителей числа 360 по разложению.

from math import isqrt

def factor(n):
    f = {}
    d = 2
    while d * d <= n:
        while n % d == 0:
            f[d] = f.get(d, 0) + 1
            n //= d
        d += 1 if d == 2 else 2
    if n > 1:
        f[n] = f.get(n, 0) + 1
    return f

def tau(n):
    r = 1
    for e in factor(n).values():
        r *= e + 1

def is_prime(n):
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    for d in range(3, isqrt(n) + 1, 2):
        if n % d == 0:
            return False
    return True

            if n <= limit and fnmatchcase(str(n), '15*3*09'):
