Теория

Что нужно знать

Задание 17 проверяет обработку последовательности чисел из файла: нужно найти количество подходящих пар, троек или окон и второй агрегат — максимум, минимум, сумму или среднее. В базе Kompege по теме 984 задачи, 66 решений (63 программных и 3 текстовых) и 232 видеоразбора (144 YouTube, 53 VK, 35 Rutube). В 2027 году тема сохраняется без изменения номера.

Файл и данные

В задании 17 числа лежат в текстовом файле, обычно по одному в строке. Программа читает весь файл в список целых чисел и дальше работает с ним по индексам. Файл 17.txt лежит рядом с программой; при запуске из другой папки путь нужно указывать явно.

  • a = [int(x) for x in open('17.txt')] читает все строки файла.
  • strip() нужен, если в файле есть пустые строки или пробелы: int(x.strip()).
  • Если числа могут быть в одной строке: a = list(map(int, open('17.txt').read().split())).
  • len(a) — количество чисел; допустимые индексы от 0 до len(a) − 1.
  • Файл можно не закрывать в короткой программе, но с with open(...) as f надёжнее.
  • Храните весь список: опорное значение может стоять в конце файла.
a = [int(x) for x in open('17.txt')]n = len(a)

Каркас решения

Почти все задачи 17 решаются по одной схеме: прочитать данные, найти опорное число по всему файлу, пройти по окнам, проверить условия, собрать подходящие суммы и вывести количество и второй агрегат.

  • Шаг 5: вывести len(b) и max(b), min(b), sum(b) или среднее.
  • Если подходящих окон нет, max упадёт — проверьте, что ответ существует.

Окна фиксированной длины

Пара — два подряд идущих элемента, тройка — три, четвёрка — четыре. Окно длины k задаётся начальным индексом i и занимает элементы a[i]…a[i+k−1]. Число окон равно n−k+1, а не n−k: последнее окно заканчивается на последнем элементе.

  • Пара: a[i], a[i+1], цикл range(n-1).
  • Тройка: a[i:i+3], цикл range(n-2).
  • Окно длины k: range(n-k+1), последний начальный индекс n-k.
  • zip(a, a[1:], a[2:]) — короткий способ идти по тройкам.
  • Для пар «через один» берите a[i] и a[i+2].
  • Для четвёрок и пятёрок срез a[i:i+k] короче и понятнее.
окон = n − k + 1for i in range(n - k + 1): w = a[i:i+k]

Опорное число

Во многих условиях есть «максимальный элемент, оканчивающийся на 13» или «минимальный двузначный, кратный сумме цифр». Такое число ищут один раз по всему файлу до основного цикла. Внутри цикла его уже не пересчитывают.

  • M = max(x for x in a if 10 <= x <= 99 and x % 10 == 3).
  • Для отрицательных чисел используйте abs(x) в условиях на цифры.
  • Гарантия «такой элемент есть» позволяет не обрабатывать пустой генератор.
  • При равенстве максимумов значение всё равно одно и то же.
  • Если условие сложное, оформите его функцией-предикатом.
  • Опорное число может быть характеристикой всего файла, а не окна.
M = max(x for x in a if P(x))m = min(x for x in a if Q(x))

Ровно, хотя бы, только один

В Python True — это 1, а False — 0. Поэтому число выполненных условий считают суммой логических выражений. Это самый короткий способ реализовать «ровно два из трёх», «хотя бы один» и «только один».

  • «Ровно k»: sum(cond(x) for x in w) == k.
  • «Хотя бы один»: any(cond(x) for x in w) или sum(...) >= 1.
  • «Ни один»: not any(...).
  • «Все»: all(cond(x) for x in w).
  • «Только один» для двух элементов: cond(x) ^ cond(y), исключающее ИЛИ.
  • Для двух разных условий: (P and not Q) or (Q and not P).
sum(bool) == kany(...), all(...), ^

Цифры числа

Свойства цифр проще всего проверять через строку str(abs(x)). Модуль убирает минус, иначе он попадёт в строку и испортит длину и сумму цифр.

  • Количество цифр: len(str(abs(x))).
  • Последняя цифра: abs(x) % 10, две последние: abs(x) % 100.
  • Сумма цифр: sum(map(int, str(abs(x)))).
  • Произведение цифр: цикл или prod из math.
  • Первая цифра: str(abs(x))[0].
  • Палиндром: s == s[::-1].
  • Цифра в середине трёхзначного числа: str(abs(x))[1].
  • Порядок цифр: сравните список цифр с sorted(...).
digits = str(abs(x))sum(map(int, digits))

Делимость и остатки

Делимость проверяют остатком %: число делится на d, если x % d == 0. Для отрицательных чисел в Python остаток неотрицательный, поэтому −14 % 7 == 0, а −3 % 10 == 7. Если важна именно последняя цифра, берите модуль.

  • x % d == 0 — делится на d.
  • abs(x) % 10 == 3 — оканчивается на 3, в том числе для отрицательных.
  • x % 2 == 0 — чётное; x % 2 == 1 — нечётное.
  • Сумма делится на d: (x + y) % d == 0.
  • Произведение делится на d: (x * y) % d == 0.
  • Разность кратна d: (x - y) % d == 0.
  • Остаток от деления на 1000 — последние три цифры.
  • Для кратности произведению проверяйте произведение целиком.
x % d == 0abs(x) % 100 == 13

Простые, квадраты, НОД

Проверка простоты — цикл до корня. Полный квадрат надёжнее проверять через isqrt, а не через x ** 0.5: плавающая точка даёт ошибки на больших числах. НОД и НОК берут из модуля math.

  • Простое: n >= 2 и нет делителей от 2 до isqrt(n).
  • Полный квадрат: r = isqrt(x); r*r == x при x >= 0.
  • НОД: gcd(x, y), НОК: x // gcd(x, y) * y.
  • Взаимная простота: gcd(x, y) == 1.
  • Количество делителей считают перебором до корня.
  • math.prod удобен для произведения цифр или элементов окна.
all(n % d for d in range(2, isqrt(n) + 1))gcd(x, y), x*y // gcd(x, y)

Системы счисления

В задании 17 часто встречаются условия про запись в семеричной, восьмеричной или шестнадцатеричной системе. Последняя цифра в системе p — это x % p, а старшую цифру находят делением на p, пока число не станет меньше p.

  • bin(x), oct(x), hex(x) дают строку с префиксом.
  • Последняя цифра в base p: x % p для неотрицательных чисел.
  • Старшая цифра: повторяйте x //= p, пока x >= p.
  • Количество цифр: цикл делений или длина строки перевода.
  • Перевести число в base p: собирайте остатки с конца.
  • «Оканчивается на 23 в base 6» — это x % 36 == 15.
  • Для отрицательных сначала берите модуль.
x % p — последняя цифраx % p**k — последние k цифр(23)₆ = 2·6 + 3 = 15

Пары любых элементов i < j

Иногда пара — это не два соседних элемента, а любые два различных элемента, порядок не важен. Полный двойной цикл делает около n²/2 проверок: при n = 10 000 это 50 млн, что на Python медленно. Если условие зависит от остатков, считайте частоты.

  • Полный перебор: for i in range(n): for j in range(i+1, n).
  • j начинается с i+1, иначе элемент сочетается сам с собой.
  • Для суммы, кратной d, храните количество предыдущих остатков.
  • Нужный остаток: need = (-x) % d.
  • Для максимума суммы храните максимальное значение по остатку.
  • «Хотя бы один делится на d» разбивайте на два счётчика.
  • Для произведения по модулю d перемножайте остатки по модулю d.
need = (-x) % dcount += cnt[need]

Кольцо, симметрия и расстояние

В закольцованной последовательности после последнего элемента идёт первый: индекс берут по модулю длины. Симметричные пары стоят на равном расстоянии от концов. Тройки на равном расстоянии делят последовательность на три части.

  • Сосед справа по кругу: a[(i+1) % n], слева: a[(i-1) % n].
  • Окно по кругу: индексы (i+k) % n.
  • Симметричная пара: a[i] и a[n-1-i].
  • Центральный элемент при нечётной длине в пары не входит.
  • Тройки на расстоянии d = n//3: zip(a, a[d:], a[2*d:]).
  • Для кольца из n элементов окно длины k даёт ровно n окон.
(i + 1) % na[i], a[n - 1 - i]d = n // 3

Агрегаты ответа

Почти всегда ответ — два числа: количество подходящих окон и второй агрегат. Вторым агрегатом бывает максимум, минимум, сумма всех сумм, среднее арифметическое или характеристика лучшего окна. Внимательно читайте, что именно просят.

  • Количество: len(b).
  • Максимум суммы: max(b), минимум: min(b).
  • Сумма всех найденных сумм: sum(b).
  • Среднее с целой частью: sum(b) // len(b).
  • Максимальный элемент среди окон: max(max(w) for w in windows).
  • Если нужен сам элемент, собирайте элементы, а не суммы.
  • Начальное значение для максимума: None или очень маленькое число.
  • −10**18 безопаснее, чем 0, если ответ может быть отрицательным.
len(b), max(b), min(b), sum(b)sum(b) // len(b)

Способы решения

Выберите метод под формулировку

Методы собраны по решениям задания 17 из базы Kompege. Начните с того, что именно нужно найти в условии.

01

когда пара — два соседних элемента

Пара подряд: базовый шаблон

Когда использовать: Условие относится к двум идущим подряд числам, а ответ — количество и максимум или минимум суммы.

  1. Прочитайте все числа в список.
  2. Найдите опорное число, если оно есть в условии.
  3. Пройдите циклом по парам a[i], a[i+1].
  4. Проверьте условие и добавьте сумму пары в список.
  5. Выведите количество и нужный агрегат.

Пример

В файле 6, 2, 9, −3, 6. Считаем пары, где хотя бы одно число делится на 3, и ищем максимальную сумму.

a = [6, 2, 9, -3, 6]

b = []
for i in range(len(a) - 1):
    x, y = a[i], a[i + 1]
    if x % 3 == 0 or y % 3 == 0:
        b.append(x + y)

print(len(b), max(b))  # 4 11

Ответ4 11.

Задача № 16264 (база Kompege); пример по мотивам задачи № 1970.

02

когда важна позиция внутри окна

Тройка подряд и центральный элемент

Когда использовать: Условие выделяет средний элемент тройки или проверяет все три позиции по-разному.

  1. Определите длину окна и позиции элементов.
  2. Опишите проверку одного элемента функцией.
  3. Пройдите по окнам через zip или срез.
  4. Проверьте условие для каждой позиции.
  5. Соберите суммы и выведите ответ.

Пример

Ищем тройки, в которых только среднее число — положительное трёхзначное, оканчивающееся на 5.

def ok(x):
    return 100 <= x <= 999 and x % 10 == 5

a = [12, 105, 37, 250, 5, 41, 8, 96, 335, 7]
b = []
for x, y, z in zip(a, a[1:], a[2:]):
    if not ok(x) and ok(y) and not ok(z):
        b.append(x + y + z)

print(len(b), max(b))  # 2 438

Ответ2 438.

Задача № 3834 (база Kompege).

03

когда окно длиннее трёх

Окно длины k: пятёрки и четвёрки

Когда использовать: Нужно проверить четыре, пять или больше подряд идущих элементов, а условия считают элементы окна.

  1. Задайте k — длину окна.
  2. Пройдите range(n-k+1).
  3. Возьмите срез a[i:i+k].
  4. Посчитайте сумму логических условий по элементам.
  5. Добавьте сумму окна и выведите агрегат.

Пример

Пятёрки, где ровно три числа оканчиваются на 4, а максимум пятёрки кратен максимальному трёхзначному числу из одинаковых цифр (777).

a = [4, 14, 24, 34, 777, 44, 4, 9, 14, 24, 34, 54]
m = max(x for x in a if 100 <= abs(x) <= 999 and len(set(str(abs(x)))) == 1)

b = []
for i in range(len(a) - 4):
    w = a[i:i + 5]
    if sum(abs(x) % 10 == 4 for x in w) == 3 and max(w) % m == 0:
        b.append(sum(w))

print(len(b), max(b))  # 2 868

Ответ2 868.

Задача № 11917 (база Kompege).

04

когда сказано «ровно два»

Ровно k условий в окне

Когда использовать: Условие требует посчитать, сколько элементов окна обладают свойством: ровно два, ровно один, не более трёх.

  1. Запишите свойство как логическое выражение.
  2. Просуммируйте выражения по элементам окна.
  3. Сравните сумму с k.
  4. Не путайте «ровно k» с «хотя бы k».
  5. Проверьте окно, где свойство выполнено у всех элементов.

Пример

Тройки, в которых нечётное число ровно одно.

a = [12, 35, 8, 7, 20, 11, 14, 9, 6]

b = []
for i in range(len(a) - 2):
    w = a[i:i + 3]
    if sum(x % 2 for x in w) == 1:
        b.append(sum(w))

print(len(b), max(b))  # 4 55

Ответ4 55.

Задача № 11625 (база Kompege).

05

когда есть максимум или минимум по условию

Опорное число с фильтром

Когда использовать: В условии есть «максимальный элемент, оканчивающийся на 7», «минимальный двузначный» или похожая характеристика всего файла.

  1. Выпишите свойство опорного числа.
  2. Найдите его генератором max или min.
  3. Убедитесь, что модуль учтён для отрицательных чисел.
  4. Используйте опорное число в условии окна.
  5. Проверьте, что в файле действительно есть такой элемент.
