Программа и траектория

Программа — это последовательность команд исполнителя. Траектория — последовательность чисел, которые получаются после каждой команды. В задании чаще всего нужно количество программ, а не количество различных траекторий.

  • Стартовое число в траекторию не включают: для программы ABA из 13 траектория — 14, 41, 42.
  • Разные программы могут приводить к одним и тем же числам, но считаются отдельно.
  • Если спрашивают «сколько различных чисел», ответ — мощность множества результатов.
  • Читайте, входит ли конечное число в траекторию: формулировки различаются.

Команды и условия применимости

Сначала выпишите все команды и проверьте, когда каждая доступна. Если команда запрещена условием, соответствующая ветка не создаётся.

  • «Поменяй местами» — только если цифра десятков меньше цифры единиц.
  • «Разделить на 2» — только для чётного, иногда только положительного числа.
  • «Возвести в квадрат» и «умножить на 3» могут перескочить цель.
  • «Прибавить сумму цифр» и «прибавить максимальную цифру» зависят от записи числа.
  • Для отрицательных чисел отдельно проверяйте целую часть и модуль.

Рекурсивная формула

Пусть f(x) — число программ из текущего числа x в целевое. Тогда f(x) равно сумме f(next) по всем допустимым командам. Граничные случаи отсекают лишние ветки.

  • f(target) = 1: пустая программа уже приводит к цели.
  • Если x > target при командах, которые только увеличивают, f(x) = 0.
  • Если x — запрещённое число, f(x) = 0.
  • Если команда недоступна, её слагаемое не добавляется.
  • Мемоизация (@lru_cache) убирает повторные вычисления.

Направление и динамика

Рекурсию можно запускать от старта к цели или от цели к старту. Для монотонных команд удобно считать f(x) с конца: f(target) = 1, затем двигаться к старту.

  • Снизу вверх: массив dp от target до start, если команды только увеличивают.
  • Сверху вниз: рекурсия с memo, если состояний немного.
  • При командах уменьшения меняйте направление и условия границ.
  • Если возможны циклы, постройте граф состояний и топологический порядок.

Обязательные числа

Если траектория обязана содержать число X, разбейте путь на два независимых участка: start → X и X → target. Количество программ перемножается.

  • Для нескольких чисел: f(start, x1) · f(x1, x2) · … · f(xk, target).
  • Числа должны идти в том порядке, в котором их можно пройти.
  • Если порядок не задан, рассмотрите все допустимые порядки и сложите варианты.
  • Запрещённые числа исключаются на каждом участке.

Запреты и «не оба»

Запрещённое число просто обнуляет ветку. Формулировка «не содержит A и B одновременно» требует вычитания: из всех программ вычитаем те, где встретились оба.

  • «Не содержит X»: if x == X: return 0.
  • «Не содержит A и B одновременно»: всего − (через A, затем B) − (через B, затем A), если оба порядка возможны.
  • «Содержит хотя бы одно из A, B»: сложите пути через A и через B и вычтите пересечение.
  • Проверьте, может ли исполнитель проходить числа в обратном порядке.

Ограничения на команды

Если есть ограничение на количество или порядок команд, добавьте в состояние дополнительный параметр: последняя команда, сколько раз использована команда, сколько чисел было чётным и т. п.

  • «Не более k раз»: параметр used; при used == k команда не добавляется.
  • «Не более двух одинаковых команд подряд»: храните последнюю команду и длину серии.
  • «После команды B только A или C»: параметр last и отдельный набор команд.
  • «Ровно k команд»: считайте состояния (число, шаг), а не только пути.

Команды над цифрами

Команды могут менять не значение, а запись числа. Реализуйте их отдельными функциями и проверяйте применимость до вызова.

  • Поменять две младшие цифры: проверить s[-2] < s[-1], затем переставить.
  • Перевернуть число: int(str(x)[::-1]); ведущие нули исчезают.
  • Прибавить сумму цифр: sum(map(int, str(x))).
  • Прибавить максимальную цифру: max(map(int, str(x))).
  • Отбросить последний разряд: x // 10.
  • Для двоичной записи: bin(x)[2:].

Когда перебор, а не формула

Если нужны все различные результаты или ровно k команд, рекурсия по путям может быть проще динамики по числу.

  • «Сколько различных чисел можно получить»: складывайте результаты в set.
  • «Ровно k команд»: передавайте номер шага и добавляйте число в set на последнем шаге.
  • Малые k (до 15–20) удобно перебирать через itertools.product.
  • Для больших k ищите закономерность или динамику по состояниям.

Проверка

Перед записью ответа проверьте программу на маленьком примере и оцените порядок числа.

  • Сравните с ручным перебором для target ≤ 20.
  • Проверьте, что не считаете пустую программу, если start ≠ target.
  • Убедитесь, что запрещённое число не совпало со стартом или целью.
  • Для больших ответов используйте Python: целые числа не переполняются.
  • Если ответ слишком велик, проверьте, не считаете ли траектории вместо программ.

Разбор примера

Учебный пример: 3 → 10, команды +1 и ×2

Посчитаем количество программ. Из каждого числа можно перейти в x + 1 и, если не перескочили цель, в 2x.

f(x) — число программ из x в 10
x109876543
f(x)11111234
  1. f(10) = 1: пустая программа уже приводит к цели.
  2. Для 9, 8 и 7 работает только команда +1, поэтому f(x) = 1.
  3. f(6) = f(7) = 1: команда ×2 даёт 12 > 10 и не рассматривается.
  4. f(5) = f(6) + f(10) = 1 + 1 = 2; f(4) = f(5) + f(8) = 2 + 1 = 3.
  5. f(3) = f(4) + f(6) = 3 + 1 = 4.
  6. Если запретить число 6, ветка 3 → 6 исчезает, и остаётся 3 программы.

Ответ4 программы; 3, если число 6 запрещено.

Способы решения

Выберите метод под формулировку

Методы собраны по решениям задания 13 из базы Kompege. Начните с того, что именно нужно найти в условии.

01

когда нет дополнительных условий

Базовая рекурсия: из A в B

Когда использовать: Нужно просто посчитать программы из одного числа в другое, а команды только увеличивают число.

  1. Выпишите команды и убедитесь, что они увеличивают число.
  2. Определите границы: если x > target, вернуть 0.
  3. Если x == target, вернуть 1.
  4. Сложите результаты для каждой команды.
  5. Добавьте @lru_cache, если состояний много.

Пример

Команды +1 и ×2, из 3 в 24. Функция перебирает оба продолжения и суммирует количество программ.

from functools import lru_cache

@lru_cache(None)
def f(x, target):
    if x > target:
        return 0
    if x == target:
        return 1
    return f(x + 1, target) + f(x * 2, target)

print(f(3, 24))

02

когда траектория должна содержать X

Обязательное число: умножаем участки

Когда использовать: В условии есть «траектория вычислений содержит число X».

  1. Найдите обязательное число X.
  2. Посчитайте программы A → X и X → B отдельно.
  3. Перемножьте количества.
  4. Если обязательных чисел несколько, перемножьте все участки.
  5. Проверьте, что порядок чисел возможен.

Пример

Команды +1, +3 и ×2; из 1 в 27; траектория содержит 9 и не содержит 15. Считаем два участка: 1 → 9 и 9 → 27.

def f(x, target):
    if x > target or x == 15:
        return 0
    if x == target:
        return 1
    return f(x + 1, target) + f(x + 3, target) + f(x * 2, target)

print(f(1, 9) * f(9, 27))

03

когда траектория не должна содержать X

Запрещённое число: обнуляем ветку

Когда использовать: В условии есть «не содержит число X» или «не проходит через X».

  1. Добавьте проверку x == X в начало функции.
  2. Верните 0, не рассматривая команды.
  3. Проверьте, что X не совпадает со стартом или целью.
  4. Если запретов несколько, перечислите их через or.

Пример

Команды +2, ×3 и ×2; из 13 в 45; запрещено число 16.

def f(x, target):
    if x >= target or x == 16:
        return x == target
    return f(x + 2, target) + f(x * 3, target) + f(x * 2, target)

print(f(13, 45))

04

когда нужно пройти 28 и 31

Несколько обязательных чисел: порядок и произведение

Когда использовать: Траектория должна содержать несколько чисел.

  1. Расположите обязательные числа по порядку.
  2. Разбейте путь на участки между ними.
  3. Перемножьте количества программ на участках.
  4. Если порядок не очевиден, проверьте все варианты.

Пример

Команды +2 и +4; из 9 в 37; траектория содержит 27 и 29 и не содержит 32.

def f(x, target):
    if x >= target or x == 32:
        return x == target
    return f(x + 2, target) + f(x + 4, target)

print(f(9, 27) * f(27, 29) * f(29, 37))

05

когда условия комбинируются

«Содержит X, но не Y» и «не оба»

Когда использовать: Нужно пройти через одно число и обойти другое или исключить одновременное появление.

  1. Для «содержит X, не содержит Y»: f(A, X) · f(X, B), где Y запрещён на обоих участках.
  2. Для «не содержит A и B одновременно»: из всех программ вычитаем те, где встретились оба.
  3. Проверьте, в каком порядке можно пройти A и B.
  4. Если возможны оба порядка, вычтите оба произведения.
  5. Если порядок один, достаточно одного вычитания.

Пример

Команды ×2, квадрат и куб; из 2 в 131 072; траектория не должна содержать 4 и 16 одновременно. Всего программ 68, через 4 и 16 проходит 36.

def f(a, b):
    if a == b:
        return 1
    if a > b:
        return 0
    return f(a * 2, b) + f(a ** 2, b) + f(a ** 3, b)

total = f(2, 131072)
both = f(2, 4) * f(4, 16) * f(16, 131072)
print(total - both)

06

когда команду можно использовать не всегда

Ограничения на команды: добавляем параметр

Когда использовать: В условии есть «не более k раз», «не подряд», «после B только A или C».

  1. Определите, чего не хватает в состоянии f(x).
  2. Добавьте параметр: последняя команда, число использований, длина серии.
  3. При переходе обновляйте параметр.
  4. В базовом случае проверьте все ограничения.
  5. Мемоизируйте по всем параметрам.

Пример

Команды +2, квадрат и ×3; из 2 в 64; после квадрата разрешены только +2 и ×3.

def f(x, target, last):
    if x > target:
        return 0
    if x == target:
        return 1
    if last == "square":
        return f(x + 2, target, "add") + f(x * 3, target, "mul")
    return (f(x + 2, target, "add")
            + f(x ** 2, target, "square")
            + f(x * 3, target, "mul"))

print(f(2, 64, ""))

07

когда команда зависит от цифр

Команды над цифрами: меняем запись числа

Когда использовать: Поменять местами, перевернуть, прибавить сумму или максимум цифр, отбросить разряд.

  1. Напишите отдельную функцию для каждой команды.
  2. Проверьте условие применимости до вызова.
  3. Помните про ведущие нули и длину числа.
  4. Для отрицательных чисел определите, как трактуется запись.
  5. Не смешивайте десятичную и двоичную запись.

Пример

Демоверсия 2027: из 100 в 141; A — прибавить 1; B — поменять две младшие цифры, если десятки меньше единиц.

def swap_last_two(x):
    s = str(x)
    if len(s) < 2 or int(s[-2]) >= int(s[-1]):
        return x
    return int(s[:-2] + s[-1] + s[-2])

def f(x, target):
    if x > target:
        return 0
    if x == target:
        return 1
    result = f(x + 1, target)
    y = swap_last_two(x)
    if y != x:
        result += f(y, target)
    return result

print(f(100, 141))

08

когда спрашивают не программы

«Сколько различных чисел»: множество результатов

Когда использовать: Нужно количество уникальных чисел после программ фиксированной длины.

  1. Создайте set для результатов.
  2. Передавайте номер шага.
  3. На последнем шаге добавляйте число в set.
  4. Не считайте одинаковые числа повторно.
  5. Для малых k можно перебрать itertools.product.

Пример

Команды +3 и −2; из 1; ровно 68 команд. Храним множество чисел после каждого шага.

states = {1}
for _ in range(68):
    states = {x + 3 for x in states} | {x - 2 for x in states}
print(len(states))

09

когда удобнее считать от цели

Обратный ход и динамика по таблице

Когда использовать: Команды уменьшают число или состояний немного.

  1. Постройте таблицу dp для чисел от target до start.
  2. dp[target] = 1.
  3. Для каждого x переберите команды, ведущие в уже посчитанные состояния.
  4. Сложите значения.
  5. Проверьте границы и запреты.

Пример

Команды −1 и −2; из 50 в 2. Считаем f(x) от 2 к 50; это числа Фибоначчи.

from functools import lru_cache

@lru_cache(None)
def f(x, target):
    if x < target:
        return 0
    if x == target:
        return 1
    return f(x - 1, target) + f(x - 2, target)

print(f(50, 2))

По мотивам задачи № 25559 (база Kompege).

10

перед записью ответа

Проверка и типичные ловушки

Когда использовать: Ответ уже получен, но нужно быстро найти обидную ошибку.

  • Проверьте, что стартовое число не считается программой, если start ≠ target.
  • Убедитесь, что обязательное число действительно входит в траекторию, а не только в программу.
  • Проверьте условие применимости каждой команды: особенно «поменяй местами» и «раздели на 2».
  • Не забудьте, что команда может перескочить цель; такие ветки дают 0.
  • Для «не содержит A и B одновременно» проверьте, не вычли ли пересечение дважды.
  • Для «ровно k команд» не путайте количество программ и количество различных результатов.
  • Для больших чисел используйте Python и memoization; проверьте глубину рекурсии.
  • Сделайте ручной перебор для target ≤ 20 и сравните ответ.
  • Проверьте, не нужно ли вернуть сумму цифр ответа или остаток.
  • Если ответ — количество программ, он не может быть отрицательным.
