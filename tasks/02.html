Теория

Что нужно знать

Задание 2 проверяет умение работать с логической функцией: прочитать выражение, построить таблицу истинности и восстановить, какой переменной соответствует каждый столбец. В 2027 году формат прежний: 1 первичный балл, раздел «Теоретические основы информатики».

Минимум для задания 2

  • пять логических операций: ¬, ∧, ∨, →, ≡
  • приоритет операций и роль скобок
  • таблицу истинности для 2–5 переменных
  • импликацию и эквивалентность через дизъюнкцию и конъюнкцию
  • законы де Моргана и двойное отрицание
  • что означают неповторяющиеся строки
  • как читать фрагмент с пустыми ячейками
  • формат ответа: буквы подряд, без разделителей

Пять логических операций

В задании 2 используются пять операций. Для каждой достаточно помнить единственный случай, когда результат отличается от очевидного.

  • ¬A (не A) — истинно тогда и только тогда, когда A ложно.
  • A ∧ B (и) — истинно только при A = 1 и B = 1.
  • A ∨ B (или) — ложно только при A = 0 и B = 0.
  • A → B (импликация) — ложно только при A = 1 и B = 0.
  • A ≡ B (эквивалентность) — истинно, когда значения A и B совпадают.
A → B = ¬A ∨ BA ≡ B = (A ∧ B) ∨ (¬A ∧ ¬B)A ≡ B = ¬(A ∧ ¬B) ∧ ¬(¬A ∧ B)

Приоритет операций

Если скобок нет, операции выполняются в таком порядке. Импликация и эквивалентность — самые слабые, поэтому в записи без скобок их выполняют последними.

  • 1. Отрицание ¬.
  • 2. Конъюнкция ∧.
  • 3. Дизъюнкция ∨.
  • 4. Импликация →.
  • 5. Эквивалентность ≡.
  • Импликация правоассоциативна: A → B → C читается как A → (B → C).
  • Если запись неоднозначна, расставьте скобки сами — так сделано в разборе задачи № 11680.

Таблица истинности и её фрагмент

Для n переменных полная таблица содержит 2^n строк: у четырёх переменных — 16, у пяти — 32. В условии дают только фрагмент, причём строки в нём не повторяются.

  • Каждая строка — отдельный набор значений переменных.
  • Порядок строк в условии не обязан быть двоичным; иногда его задают словами «по возрастанию».
  • Столбцы переменных переставлены и не подписаны — именно их и нужно восстановить.
  • Пустая ячейка означает, что значение может быть любым; такие ячейки перебирают.
  • «Неповторяющиеся строки» — подсказка: двух одинаковых наборов в таблице быть не может.

Равносильные преобразования

Упрощение выражения часто делает очевидным, при каких наборах F = 1 или F = 0. Эти формулы стоит держать в голове.

  • Импликацию заменяют дизъюнкцией: A → B = ¬A ∨ B.
  • Эквивалентность раскрывают через совпадение значений или через две импликации.
  • Законы де Моргана: ¬(A ∧ B) = ¬A ∨ ¬B и ¬(A ∨ B) = ¬A ∧ ¬B.
  • Двойное отрицание: ¬¬A = A.
  • Поглощение: A ∧ (A ∨ B) = A и A ∨ (A ∧ B) = A.
¬(A ∧ B) = ¬A ∨ ¬B¬(A ∨ B) = ¬A ∧ ¬BA → B = ¬A ∨ B

Опорные признаки во фрагменте

Прежде чем перебирать, поищите во фрагменте закономерности: они часто дают ответ без вычислений.

  • Столбец целиком из единиц: переменная равна 1 во всех допустимых строках.
  • Столбец целиком из нулей: переменная равна 0 во всех допустимых строках.
  • Сравнивайте не только расположение, но и количество единиц: если у переменной в допустимых наборах две единицы, столбец с тремя единицами — не она.
  • Если F одинаков во всех строках, выгодно выписать все наборы, где функция принимает это значение.
  • Если картина 0/1 у двух столбцов совпала, различие ищут по строкам с пустыми ячейками.

Формат ответа

Ответ зависит от формулировки, и проверяется он автоматически, поэтому важна каждая буква.

  • «Какому столбцу соответствует каждая переменная» — строка букв слева направо, например wxzy.
  • «Значения a, b, c, d» — цифры подряд в порядке букв, например 00101 (задача № 6837).
  • «Сколько существует вариантов расстановки» — одно число (задачи № 12643, 13974, 14497).
  • «При каких значениях выражение ложно» — строка из нулей и единиц в порядке переменных (задача № 20919).
  • Пробелы, запятые и другие разделители в ответе недопустимы.

  1. F — конъюнкция трёх импликаций, поэтому F = 1 только тогда, когда истинны все три.
  2. Из b → ¬c следует, что b и c не равны 1 одновременно; из ¬c → d следует, что c = 1 или d = 1. Перебор 16 наборов даёт пять строк второй таблицы.
  3. В третьей строке фрагмента три единицы: (1, ·, 1, 1). Среди наборов с F = 1 только 1101 содержит три единицы, поэтому единицы стоят в столбцах переменных a, b и d, а второй столбец — c.
  4. Первый столбец равен 1 во всех строках. Переменная a равна 1 только в одном наборе, b — в двух, d — в четырёх, поэтому три различные строки с единицей в первом столбце может дать только d.

Способы решения

Выберите метод под формулировку

Методы собраны по решениям задания 2 из базы Kompege. Начните с того, что именно нужно найти в условии.

01

когда во всех строках одно и то же F

Разбор от значения F

Когда использовать: Фрагмент содержит только строки с F = 1 или только с F = 0, а выражение разбирается по частям: конъюнкции, дизъюнкции, импликации.

  1. Подставьте значение F в выражение и выпишите, что из этого следует для каждой части.
  2. Для конъюнкции истинны должны быть все части, для дизъюнкции — хотя бы одна.
  3. Найдите переменные, чьё значение в подходящих наборах постоянно.
  4. Сопоставьте эти переменные со столбцами фрагмента по картине 0 и 1.
  5. Оставшиеся столбцы разберите по строкам, где больше всего заполненных ячеек.

Пример

В задаче № 9905 F = (x → y) ∧ (y → z) ∧ (z → w). Конъюнкция импликаций истинна только при x ≤ y ≤ z ≤ w, то есть на наборах 0000, 0001, 0011, 0111 и 1111. Первая и последняя строки не подходят под фрагмент, остаются 0001, 0011 и 0111: в них w всегда 1, а x всегда 0. Значит, первый столбец — w, второй — x. Строка (1, 0, 1, 0) соответствует набору 0011, поэтому третий столбец — z, четвёртый — y.

Ответwxzy.

По мотивам задачи № 9905 (база Kompege).

02

когда наборы уже выписаны

Сопоставление по картине нулей и единиц

Когда использовать: Есть список наборов, где F = 1 или F = 0, и нужно быстро разложить их по столбцам фрагмента.

  1. Посчитайте, в скольких допустимых наборах каждая переменная равна 1.
  2. Посчитайте то же для каждого столбца фрагмента, не учитывая пустые ячейки.
  3. Начните с редких картин: столбец с тремя единицами не может быть переменной с одной единицей.
  4. Если картина совпала у двух переменных, уточните соответствие по конкретным строкам.
  5. После расстановки проверьте каждую строку фрагмента.

Пример

В задаче № 14297 F = ¬i ∧ (f → o) ∧ n истинна на трёх наборах: 0100, 0101 и 0111 в порядке i, n, f, o. Значит, n равна 1 три раза, o — два раза, f — один раз, i — ни разу. Во фрагменте третий столбец содержит три единицы, второй — две, первый — одну, а четвёртый не содержит единиц вовсе: получаем f, o, n, i.

Ответfoni.

По мотивам задачи № 14297 (база Kompege).

03

когда переменных три или четыре

Полная таблица истинности

Когда использовать: Нужно увидеть все строки функции целиком: так проще отсеять наборы, которых во фрагменте быть не может.

  1. Выпишите все наборы для n переменных: 8 строк для трёх, 16 для четырёх.
  2. Оставьте только строки с тем значением F, которое стоит во фрагменте.
  3. Уберите строки, не подходящие под заполненные ячейки фрагмента.
  4. Сопоставьте оставшиеся наборы со строками и определите столбцы.
  5. Проверьте, что строки фрагмента не повторяются.

Пример

В задаче № 11220 F = (x → y) ∧ z ∧ ¬w. Из F = 1 сразу следует z = 1 и w = 0, поэтому подходят только наборы 0010, 0110 и 1110 в порядке x, y, z, w. В третьей строке фрагмента три единицы: (0, 1, 1, 1). Среди наборов только 1110 содержит три единицы, а единственный нуль в нём — это w, значит, первый столбец — w. Первая строка (0, 1, ·, 1) не может совпасть с третьей, поэтому она равна 0110: третий столбец — x, четвёртый — y. Вторая строка даёт 0010 и подтверждает, что второй столбец — z.

Ответwzxy.

По мотивам задачи № 11220 (база Kompege).

04

универсальный способ

Перебор на Python

Когда использовать: Сложное выражение, 4–5 переменных и много пустых ячеек: вручную разбор получается долгим.

  1. Запишите функцию на Python: not, and, or; A → B как a <= b, A ≡ B как a == b.
  2. Соберите строки фрагмента кортежами, заменив пустые ячейки переменными a1, a2, …
  3. Переберите значения неизвестных через product([0, 1], repeat=k).
  4. Пропустите варианты с повторяющимися строками: len(table) != len(set(table)).
  5. Переберите перестановки имён через permutations и выведите те, при которых значения функции совпадают с F.
  6. Если пустых ячеек нет, product не нужен: сразу перебирайте permutations по строкам (задача № 11680).

Пример

Шаблон для учебного примера: шесть неизвестных ячеек, четыре переменные.

from itertools import product, permutations

def f(a, b, c, d):
    return (a <= b) and (b <= (not c)) and ((not c) <= d)

for a1, a2, a3, a4, a5, a6 in product([0, 1], repeat=6):
    table = [(1, a1, a2, a3), (1, a4, 1, a5), (1, a6, 1, 1)]
    if len(table) != len(set(table)):
        continue
    for p in permutations("abcd"):
        if all(f(**dict(zip(p, row))) for row in table):
            print(*p, sep="")

Ответdcba

Шаблон по мотивам решений задач № 11220, 11606, 16249 и 27964.

05

когда формула громоздкая

Упрощение и разбор по частям

Когда использовать: Выражение содержит импликации, эквивалентности и отрицания целых скобок — после преобразования видно, когда F = 0.

  1. Избавьтесь от импликаций: A → B = ¬A ∨ B.
  2. Раскройте эквивалентность или замените её на совпадение значений.
  3. Внесите отрицание внутрь по законам де Моргана.
  4. Сократите повторяющиеся части по закону поглощения.
  5. Прочитайте, при каких значениях F = 0 или F = 1, и сопоставьте результат с фрагментом.

Пример

В задаче № 20919 нужно найти набор, при котором (K ∨ M) → (M ∨ ¬L ∨ N) ложно. Импликация ложна только при истинной левой и ложной правой части: K ∨ M = 1, а M = 0, L = 1, N = 0. Отсюда K = 1.

Ответ1100.

06

когда ответ — не строка букв

Нестандартные формулировки

Когда использовать: Спрашивают количество вариантов, значения неизвестных или добавляют условие на столбцы и строки.

  • «Сколько существует вариантов расстановки»: переберите permutations и посчитайте подходящие — задачи № 12643 (ответ 3), № 13974 (ответ 2) и № 14497 (ответ 8).
  • «Значения a, b, c, d»: перебирайте неизвестные и сверяйте с F; ответ — цифры подряд, например 00101 в задаче № 6837.
  • «Значения строк возрастают»: сравнивайте строки как двоичные числа — задача № 10915 (ответ zywx).
  • «Значение столбца w больше значения столбца y»: сравните столбцы как двоичные числа — задача № 11680 (ответ yzxw).
  • Даны две функции F1 и F2: столбцы общие для обеих, проверять нужно обе — задача № 14497.
  • Если переменных пять, в ответе тоже пять букв: не потеряйте ни одну.

По мотивам задач № 6837, 10915, 11680, 12643, 13974 и 14497.
