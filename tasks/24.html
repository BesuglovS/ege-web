Теория

Что нужно знать

Задание 24 — это программирование, а не ручной счёт. Почти всегда нужно прочитать одну длинную строку из файла и найти в ней подстроку с ограничением: без запрещённых букв, с заданным числом вхождений, с равным количеством двух символов или с определённой структурой. Ответ — одно число, но получить его без ошибок можно только аккуратной программой.

Минимум для задания 24

  • прочитать строку из файла и убрать перевод строки
  • понимать индексацию с нуля и срезы
  • применять len, count, find, replace, split и join
  • писать цикл по символам и по индексам
  • поддерживать счётчики и левую границу окна
  • отличать подстроку от подпоследовательности
  • проверять палиндром и группы символов
  • узнавать задачи на префиксные суммы
  • применять регулярные выражения для поиска и подсчёта вхождений
  • писать двойной цикл, когда условие сложно поддерживать окном
  • оценивать сложность при 10^6 символов
  • проверять границы среза и пустые строки

Файл и строка

В задании 24 данные лежат в текстовом файле. Чаще всего это одна очень длинная строка — до 10^6 символов. Читать её через input() нельзя: нужен файл. Для одной строки хватает readline(), для нескольких — read().splitlines().

  • s = open('24.txt').readline() читает первую строку вместе с переводом строки.
  • s = s.strip() убирает пробельные символы по краям; если важны пробелы в начале, используйте rstrip().
  • Для нескольких строк: lines = open('24.txt').read().splitlines().
  • Файл лучше открывать в блоке with, но на экзамене достаточно одной строки open(...).readline().
  • Размер 10^6 символов означает, что алгоритм должен быть линейным или близким к линейному.
s = open('24.txt').readline().strip()lines = open('24.txt').read().splitlines()n = len(s)

Индексация и срезы

Строка в Python — последовательность символов с нумерацией от нуля. Срез s[i:j] берёт символы с i до j, не включая j. Это главный источник ошибок: длина среза равна j − i, а последний индекс — j − 1.

  • s[0] — первый символ, s[-1] — последний.
  • s[i:j] — с i по j-1; s[:k] — первые k; s[i:] — до конца.
  • len(s[i:j]) = max(0, j - i).
  • s[::-1] — перевёрнутая строка; s[i:j:k] — с шагом k.
  • Для окна длины L, начинающегося в i: s[i:i+L]; последний старт — len(s)-L.
s[i:j] = s[i], …, s[j-1]len(s[i:j]) = j - iокно длины L: i от 0 до len(s)-L

Встроенные операции

Большую часть задания можно решить без ручных циклов, если правильно выбрать строковую операцию. Важно помнить, что count считает непересекающиеся вхождения, find возвращает -1 при отсутствии, а replace заменяет все вхождения.

  • len(s), s.count(x), s.find(x), s.rfind(x).
  • s.replace(a, b) — все вхождения; s.replace(a, b, k) — первые k.
  • s.split(sep) — список частей; s.split() — по любым пробелам.
  • sep.join(parts) — склеить список обратно.
  • x in s, s.startswith(x), s.endswith(x) — проверки.
  • count и replace не перекрывают вхождения: в 'AAA' строка 'AA' встречается один раз.
s.count(x) — число непересекающихся вхожденийs.find(x) → индекс или -1s.replace(x, y) → новая строка

Подстрока и подпоследовательность

Подстрока — это непрерывный кусок строки. Подпоследовательность — набор символов в порядке следования, но не обязательно подряд. В задании 24 чаще нужна подстрока; если в условии сказано «подпоследовательность», нельзя использовать срез s[i:j] и скользящее окно без учёта разрывов.

  • «идущих подряд» — подстрока, окно или срез.
  • «подпоследовательность» — можно пропускать символы, обычно нужен другой алгоритм.
  • «количество подстрок» — важно, считать ли вхождения с перекрытиями.
  • «длина подстроки» — ответ в символах, а не в количестве вхождений.
  • Проверьте по примерам из условия, что именно считается подстрокой.
подстрока: s[i:j]подпоследовательность: индексы i₁ < i₂ < …

Скользящее окно

Скользящее окно — основной приём для задач «максимальная длина при ограничении на количество символов». Правая граница добавляет символ, левая убирает, пока окно не станет допустимым. Каждый символ входит в окно и выходит из него не более одного раза, поэтому алгоритм линейный.

  • left = 0; для right от 0 до len(s)-1 добавляйте s[right].
  • Пока условие нарушено, вычитайте s[left] и увеличивайте left.
  • После восстановления условия обновляйте ответ: right - left + 1.
  • «Не более K» — цикл while count > K.
  • «Ровно K» — обновляйте ответ только при count == K, а окно держите не больше K.
  • «Не менее K» — обычно проще считать через префиксные суммы или хранить первое вхождение.
длина окна = right - left + 1амортизированно O(n): right и left двигаются только вперёд

Префиксные суммы

Если нужно сравнивать количества двух символов, удобно превратить строку в последовательность +1 и −1. Тогда равное количество означает одинаковую префиксную сумму. Самый длинный отрезок с равными количествами — это расстояние между первым и последним вхождением одного и того же значения префикса.

  • P[0] = 0; P[i+1] = P[i] + вес(s[i]).
  • Вес: +1 для одного символа, −1 для второго, 0 для остальных.
  • Храните первое вхождение каждого значения P в словаре.
  • Для отрезка i+1…j нужно P[i] == P[j]; длина = j - i.
  • Для «ровно K» ищите P[j] - P[i] == K, то есть P[i] == P[j] - K.
  • Для двух условий сразу используйте кортеж из двух префиксных сумм.
P[j] - P[i] = количество A − количество B на отрезкеравные количества: P[i] = P[j]ровно K: P[i] = P[j] - K

Группы и повторения

Иногда строка состоит из повторяющихся групп или блоков одинаковых символов. Тогда удобно сжать её в список пар (символ, количество) или идти по строке с состоянием — каким должен быть следующий символ.

  • Подряд идущие одинаковые символы собирайте в группы: 'AAABB' → [('A', 3), ('B', 2)].
  • Для группы WXYZ проверяйте, что следующий символ продолжает цикл: W→X→Y→Z→W.
  • Для RLE длина кодировки = сумма цифр в количествах + число групп.
  • Если группа может быть неполной в начале и конце, разрешите начать с любого символа шаблона.
  • Для «ровно N полных групп» делите длину цепочки на длину группы.
RLE: 'AAAB' → '3A1B' или '3AB'длина RLE = число групп + количество цифр в записях количествпозиция в шаблоне = i mod len(pattern)

Палиндромы

Палиндром читается одинаково в обе стороны. Проверка — s == s[::-1]. Для подсчёта палиндромов фиксированной длины переберите все окна; для самого длинного — расширяйте центр; для задачи о заменах — считайте нечётные частоты.

  • Проверка: s == s[::-1].
  • Палиндром чётной длины имеет центр между символами, нечётной — в символе.
  • Любой палиндром длины больше 3 содержит палиндром длины 2 или 3.
  • Для подсчёта окон длины L: for i in range(len(s)-L+1).
  • Чтобы собрать палиндром перестановками, нечётных частот должно быть не больше одной.
  • Минимальное число замен для палиндрома: количество нечётных частот // 2.
s == s[::-1]число окон длины L = len(s) - L + 1замены = odd // 2

Числа и слова в строке

Если строка содержит буквы и цифры, её удобно разбить на «слова» или «числа», заменив лишние символы пробелами. Затем split() отбрасывает пустые части, а int() или len() дают нужную величину.

  • Цифры: замените все нецифровые символы пробелами и вызовите split().
  • Слова: замените цифры пробелами; словом считается непрерывный блок букв.
  • Для максимального числа сравнивайте int(x), а не строки: '9' > '10' лексикографически.
  • Ведущие нули в IP-адресе недопустимы, хотя int('012') = 12.
  • Для IP делите по точкам и проверяйте 4 части, каждую в диапазоне 0…255.
  • Маску проверяйте посимвольно: '?' означает любую цифру.
replace для замены классов символовmax(map(int, parts))0 ≤ part ≤ 255, 4 части, без ведущих нулей

Регулярные выражения

Регулярное выражение — это шаблон, по которому ищут подстроки. В задании 24 оно помогает, когда нужно найти все числа, слова, пары «буква-цифра», арифметические выражения или пересекающиеся вхождения. Шаблон читается слева направо, а квантификаторы задают количество повторений.

  • import re; основные функции — re.findall, re.finditer, re.search и re.sub.
  • Классы: \d — цифра, \w — буква или цифра, [A-Z] — диапазон, [^0-9] — любой символ, кроме цифры.
  • Квантификаторы: + одно и более, * ноль и более, ? ноль или один, {m,n} от m до n повторов.
  • Жадные * и + захватывают максимум; ленивые *? и +? — минимум.
  • Группы (...) позволяют достать часть совпадения через m.group(1).
  • Для пересекающихся вхождений используйте lookahead: re.finditer(r'(?=(ABA))', s).
  • Для арифметического выражения подходит шаблон (\d+)([+*\-])(\d+); результат проверяйте по всем совпадениям.
  • Если совпадений нет, findall вернёт пустой список — обработайте этот случай отдельно.
re.findall(r'\d+', s) — все числаre.finditer(r'(?=(ABA))', s) — пересекающиеся вхожденияre.sub(r'[^0-9]', ' ', s) — заменить всё, кроме цифр

Сложность и проверка

При длине 10^6 квадратичный алгоритм может работать минуты. Считайте количество операций: один проход — хорошо, вложенный цикл по всем парам — плохо. Перед сдачей проверьте программу на короткой строке, где ответ можно посчитать вручную.

  • O(n) — один проход, окно, префиксные суммы; O(n²) — перебор всех пар границ.
  • Не вызывайте s.count() или s.find() внутри цикла по всем i без необходимости.
  • Проверьте пустую строку, строку из одного символа и случай без подходящих подстрок.
  • Проверьте границы среза: range(len(s)-L+1), а не range(len(s)-L).
  • Убедитесь, что ответ — целое число, как требует бланк.
  • Для отладки выведите длину строки и первые/последние символы.
n = 10^6: O(n) — норма, O(n²) — слишком долгоответ — одно целое число

Замена и split: запрещённые символы

Когда использовать: Нужно найти максимальный отрезок, в котором нет заданных символов, или разбить строку на допустимые блоки.

  1. Прочитайте строку и уберите перевод строки.
  2. Замените каждый запрещённый символ на пробел.
  3. Разбейте строку по пробелам через split().
  4. Возьмите max(len(part)) или min(len(part)) по непустым частям.
  • Заменять можно в цикле по набору запрещённых символов.
  • split() без аргумента делит по любым пробелам и убирает пустые части.
  • Если запрещена подстрока, а не символ, замените её на пробел целиком.
  • Для количества подходящих блоков используйте len(parts).

Пример

Строка ABCXAB, запрещены буквы A и B. Найдите длину самого длинного блока без запрещённых букв.

s = open('24.txt').readline().strip()
for ch in 'AB':
    s = s.replace(ch, ' ')
print(max(len(part) for part in s.split()))

02

ограничение на число символов

Скользящее окно: не более и ровно K

Когда использовать: Нужно максимизировать длину подстроки при условии «не более K», «ровно K» или «не менее K» вхождений.

  1. Заведите left = 0 и счётчик нужных символов.
  2. Для right от 0 до len(s)-1 добавляйте s[right] в счётчик.
  3. Пока счётчик больше K, вычитайте s[left] и увеличивайте left.
  4. Обновляйте ответ длиной right - left + 1.
  • Для «не более K» окно всегда допустимо после цикла while.
  • Для «ровно K» обновляйте ответ только при count == K.
  • Для нескольких символов храните словарь счётчиков.
  • Для вхождений подстроки считайте непересекающиеся вхождения или используйте find с шагом.

Пример

Строка ABBCAABBC. Найдите максимальную длину подстроки, в которой не более двух букв B.

s = open('24.txt').readline().strip()
left = count = best = 0
for right in range(len(s)):
    if s[right] == 'B':
        count += 1
    while count > 2:
        if s[left] == 'B':
            count -= 1
        left += 1
    best = max(best, right - left + 1)
print(best)

ОтветДля ABBCAABBC подходят отрезки ABBCAA и CAABBC длины 6; ответ 6.

03

баланс, равное число A и B

Префиксные суммы: равные количества и разность

Когда использовать: Нужно найти самый длинный отрезок с равным количеством двух символов или с заданной разностью счётчиков.

  1. Присвойте одному символу +1, второму −1, остальным 0.
  2. Считайте текущую сумму P и сохраняйте первое вхождение каждого значения в словарь.
  3. Если значение уже встречалось, длина отрезка = текущий индекс − сохранённый индекс.
  4. Для «ровно K» ищите значение P - K.
  5. Для двух условий используйте кортеж из двух сумм.
  • Словарь first начинайте с {0: 0} — пустой префикс.
  • Сохраняйте именно первое вхождение, иначе отрезок будет короче.
  • Индексы в словаре — это количество символов до текущей позиции.
  • Для одной буквы и «ровно K» можно хранить префиксные количества.

Пример

Строка ABACBBACAA. Найдите максимальную длину подстроки с равным количеством A и B.

s = open('24.txt').readline().strip()
first = {0: 0}
balance = best = 0
for i, ch in enumerate(s, start=1):
    if ch == 'A':
        balance += 1
    elif ch == 'B':
        balance -= 1
    if balance in first:
        best = max(best, i - first[balance])
    else:
        first[balance] = i
print(best)

По решениям № 10131, 14242.

04

одинаковые подряд, группы WXYZ

Группы, повторы и RLE

Когда использовать: Строка состоит из повторяющихся групп, нужно найти цепочку вида WXYZ…, максимальное число одинаковых подряд или посчитать сжатие.

  1. Сожмите строку в группы (символ, количество).
  2. Проверяйте соседние группы на нужный шаблон.
  3. Для периодического шаблона используйте состояние: какой символ должен идти следующим.
  4. Для RLE считайте длину кодировки и сравнивайте с исходной.
  • itertools.groupby упрощает сбор групп.
  • Для WXYZ допустим переход W→X→Y→Z→W.
  • В начале и конце группа может быть неполной — это разрешают отдельно.
  • При RLE количество из одной цифры занимает один символ; из 10 и более — два и больше.

Пример

Строка AAAABBBCCDAA. Найдите длину RLE-кодировки и экономию в битах, если каждый символ занимает 8 бит.

s = open('24.txt').readline().strip()
parts = []
i = 0
while i < len(s):
    j = i

Когда использовать: Нужно посчитать палиндромы заданной длины, найти самый длинный палиндром или минимальное число замен.

  1. Проверяйте палиндром сравнением s == s[::-1].
  2. Для фиксированной длины переберите все окна.
  3. Для самой длинной цепочки расширяйте центр в обе стороны.
  4. Для замен считайте количество символов с нечётной частотой.
  • Окон длины L ровно len(s) - L + 1.
  • Палиндром длины больше 3 содержит палиндром длины 2 или 3.
  • Для перестановок в палиндром допустим не более одного нечётного счётчика.
  • Минимальное число замен = odd // 2.

Пример

s = open('24.txt').readline().strip()
best = 0
for center in range(len(s)):
    for left, right in ((center, center), (center, center + 1)):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            best = max(best, right - left + 1)
            left -= 1
            right += 1
count3 = sum(s[i:i+3] == s[i:i+3][::-1] for i in range(len(s) - 2))

  2. Добавляйте s[right]; пока символ уже есть, удаляйте s[left] и двигайте left.

  • Для запрета палиндромов длины больше 1 достаточно запретить длины 2 и 3.
  • Сдвигайте left на нужную позицию, а не на единицу, если так проще.

08

шаблон вместо ручного цикла

Регулярные выражения

Когда использовать: Нужно найти все вхождения шаблона: числа, слова, пары символов, арифметические выражения или пересекающиеся подстроки.

  1. Импортируйте re и прочитайте строку.
  2. Опишите шаблон классами и квантификаторами.
  3. Для непересекающихся вхождений используйте re.findall или re.finditer.
  4. Для пересекающихся — оберните шаблон в lookahead (?=...).
  5. Если нужны части совпадения, добавьте группы и берите m.group(1).
  6. Проверьте жадность квантификаторов и пустой результат.
  • re.findall возвращает список строк или кортежей групп.
  • re.finditer возвращает объекты совпадений с позициями start() и end().
  • Шаблон r'\d+' найдёт все числа, включая многозначные.
  • Шаблон r'[A-Z]+' найдёт последовательности заглавных букв.
  • Для арифметического выражения берите nums = [int(x) for x in re.findall(r'\d+', m.group(0))].
  • Lookahead (?=...) не сдвигает позицию, поэтому находит перекрывающиеся вхождения.

Пример

Строка A12+B3*C2024D. Найдите все числа и количество пересекающихся вхождений ABA в строке ABABA.

import re

s = "A12+B3*C2024D"
nums = [int(x) for x in re.findall(r'\d+', s)]
overlap = len(re.findall(r'(?=ABA)', "ABABA"))
print(nums, max(nums), overlap)

ОтветЧисла [12, 3, 2024], максимум 2024; в ABABA два пересекающихся вхождения ABA (позиции 0 и 2).

09

когда условие сложно поддерживать окном

Двойной цикл

Когда использовать: Нужно перебрать все подстроки, а условие содержит несколько независимых счётчиков, порядок символов или запрет на конкретные сочетания.

  1. Для каждого left заведите пустые счётчики.
  2. Двигайте right вправо и обновляйте счётчики.
  3. Если условие нарушено, прервите внутренний цикл.
  4. Обновляйте лучшую длину right - left + 1.
  5. Проверьте сложность: O(n·L), где L — длина ответа.
  • Двойной цикл удобен, когда условие трудно сформулировать для скользящего окна.
  • Если ответ короткий, внутренний цикл быстро обрывается и решение проходит.
  • Для 10^6 символов и длинного ответа O(n²) может не уложиться в лимит — тогда нужно окно или префиксные суммы.
  • Счётчики можно хранить в dict или в массиве на 26 букв.
  • Для запрета двух одинаковых соседних символов проверяйте s[right] == s[right-1].

Пример

Строка AABACAA. Найдите максимальную длину подстроки, в которой не более двух букв A.

s = "AABACAA"
best = 0
for left in range(len(s)):
    count_a = 0
    for right in range(left, len(s)):
        if s[right] == 'A':
            count_a += 1
        if count_a > 2:
            break
        best = max(best, right - left + 1)
print(best)

ОтветПодходят ABAC и BACA длины 4; ответ 4.

По видео 2025 года, глава «Двойной цикл».
