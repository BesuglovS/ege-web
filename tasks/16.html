Теория

Что нужно знать

Задание 16 проверяет рекурсию: значение функции F(n), количество вызовов, сумму или количество выведенных символов, иногда — неизвестный параметр. В базе Kompege по теме 1 011 задач, 70 решений (61 программное и 9 текстовых) и 260 видеоразборов (161 YouTube, 66 VK, 33 Rutube). В 2027 году тема сохраняется без изменения номера.

Минимум для задания 16

  • базовый случай и рекурсивный шаг
  • дерево вызовов и порядок обхода
  • линейная рекурсия F(n−1) и F(n−2)
  • рекурсия вперёд: F(n+1), F(n+2), F(2n)
  • ветвление по чётности, делимости и значению предыдущего вызова
  • две и более взаимно рекурсивные функции
  • таблица значений и динамика снизу вверх
  • мемоизация: @lru_cache, @cache, словарь
  • подсчёт количества вызовов и узлов дерева
  • вывод на экран: звёздочки, числа и порядок print
  • суммы значений, арифметическая прогрессия и большие n
  • целочисленное деление //, остаток % и отрицательные n
  • обратная задача: найти x или границу
  • проверка ответа и ограничение глубины рекурсии

Рекурсивная функция и её части

Рекурсивная функция вызывает саму себя с другим аргументом. В задании 16 всегда есть базовый случай, который не делает нового вызова, и рекурсивный шаг. Без базы вычисление не завершится, а неверная база даст неверный ответ.

  • Базовый случай возвращает значение сразу: обычно при n ≤ b или n ≥ N.
  • Рекурсивный шаг приближает аргумент к базе: n−1, n−2, n//2 или n+1 при базе сверху.
  • Условия в записи читаются сверху вниз; срабатывает первая подходящая ветвь.
  • Ветвь может зависеть от n, от n % 2, от n % 3 или от значения F(n−1).
  • Аргументов может быть несколько: F(a, b), F(n, s), F(n, flag).
F(n) = база, если условиеF(n) = выражение с F(...), иначе

Дерево вызовов

Каждый вызов — узел дерева. Листья — базовые случаи. Значение считается снизу вверх: сначала листья, затем родители. Дерево помогает не потерять ветвь и посчитать количество вызовов.

  • Корень — исходный вызов F(n).
  • Дети — вызовы, которые делает текущий вызов.
  • Лист — вызов, попавший в базовый случай.
  • Количество вызовов — число узлов дерева, включая корень и листья.
  • Глубина дерева — максимальная длина цепочки вызовов.
  • Для больших n дерево не рисуют полностью, а сворачивают в таблицу или формулу.
вызовов = 1 + Σ вызовов в детяхзначение = шаг(значения детей)

Линейная рекурсия

Если в правой части один вызов, вычисление идёт цепочкой. Если два вызова, появляется ветвление. Цепочку раскрывают подстановкой, пока не дойдут до базы, а затем считают снизу вверх.

  • F(n) = n + F(n−1) даёт сумму n + (n−1) + … + F(b).
  • F(n) = n·F(n−2) даёт произведение чисел той же чётности.
  • При базе n ≤ b подстановку останавливают на первом n из базы.
  • Шаг n−2 сохраняет чётность: чётные и нечётные цепочки не пересекаются.
  • Для произведения следите за нулём: F(0) = 0 обнулит всю цепочку.
F(n) = n + (n−1) + … + (b+1) + F(b)F(n) = n·(n−2)·…·(b+2)·F(b)

Рекурсия вперёд

Если база задана при n ≥ N, а шаг увеличивает аргумент, вычисляют в обратном порядке: от границы базы вниз к нужному n. Таблицу заполняют с конца.

  • Определите границу базы: n ≥ N, n > N или n = N.
  • Начинайте с наибольшего n и двигайтесь вниз.
  • При шаге 2n значения нужны только для степеней двойки.
  • Если аргумент уходит за границу, срабатывает база.
  • Для F(5) при шаге 2n цепочка: 5 → 10 → 20 → … до базы.
F(N) = база; F(N−1), F(N−2), … — обратный ходF(2n) требует значения только в точках 2^k·n

Ветвление по условиям

В задании 16 ветвь часто выбирается по чётности n, остатку от деления или значению предыдущего вызова. Сначала вычислите условие, затем выбирайте формулу. Порядок условий важен: ветви могут пересекаться.

  • n % 2 == 0 — чётное; n % 2 == 1 — нечётное.
  • n % 3 == 0 — делится на 3; проверяйте остатки 0, 1 и 2.
  • Условие может смотреть на F(n−1): «если F(n−1) чётно».
  • Для отрицательных n в Python остаток неотрицательный: −3 % 10 = 7.
  • Если условие не выполнено ни для одной ветви, функция не определена — проверьте базу.
ветвь 1, если условие 1ветвь 2, если условие 2ветвь 3, иначе

Таблица и динамика

Вместо рекурсии значения хранят в массиве или словаре и заполняют по порядку. Это снимает повторные вычисления и риск переполнения стека. Для рекурсии вперёд порядок заполнения обратный.

  • Заведите массив на диапазон от базы до нужного n.
  • Сначала заполните базовые значения.
  • Затем применяйте формулу для n по возрастанию или по убыванию.
  • Для F(n−2) нужны два предыдущих значения, для F(n−5) — пять.
  • Для двух функций храните два массива или пары значений.
  • Проверка: f[n] должно совпадать с рекурсивным вызовом на малых n.
f[n] = выражение(f[n−1], f[n−2], …)f[n] = f[n−1] + f[n−2] — числа Фибоначчи

Мемоизация

Мемоизация кэширует результат для каждого аргумента. Один и тот же F(k) не вычисляется повторно, поэтому дерево превращается в граф зависимостей и работает за число различных аргументов.

  • from functools import lru_cache; @lru_cache(None) ставится перед def.
  • В Python 3.9+ доступен @cache как короткий вариант.
  • Кэш работает только для хешируемых аргументов: int, tuple, str.
  • Для больших n прогрейте кэш циклом или увеличьте глубину рекурсии.
  • Мемоизация не меняет значение функции, только скорость.
  • Не используйте кэш, если функция зависит от внешней изменяемой переменной.
@lru_cache(None)from functools import cache

Количество вызовов

Количество вызовов — это не значение функции, а размер дерева. Для одного вызова это 1 плюс число вызовов детей. Если считают только рекурсивные вызовы, корень может не учитываться — уточняйте формулировку.

  • Если считают все обращения к функции, каждый узел даёт 1.
  • Для F(n) = F(n−1) + F(n−2) число вызовов растёт как числа Фибоначчи.
  • Мемоизация уменьшает число вычислений, но не число обращений в наивной программе.
  • Для процедуры с print считайте каждый вход в процедуру.
  • Формулу удобно проверить на малых n вручную.
  • Ответ может быть очень большим; в Python он не переполняется.
C(n) = 1, если базаC(n) = 1 + C(n−1) + C(n−2)

Что выводит процедура

В задачах со звёздочками и числами важен порядок команд: print до рекурсивного вызова выполняется при каждом входе, print после — при возврате. Суммируйте вклад текущего вызова и детей.

  • Один print внутри процедуры — одна единица вклада на каждый вызов.
  • print после рекурсивного вызова тоже выполняется, но позже.
  • Если print стоит под if, он добавляется только при истинном условии.
  • Для звёздочек: S(n) = вклад текущего вызова + S(детей).
  • Для чисел складывайте напечатанные значения, а не аргументы.
  • Порядок вывода влияет на последовательность, но не на сумму и количество.
S(n) = print_сейчас + S(n−1) + S(n−2)количество = сумма вкладов всех вызовов

Суммы и большие n

Если нужна сумма F(k) на отрезке или значение при большом n, рекурсию сворачивают в формулу. Часто помогают арифметическая прогрессия, суммы квадратов и периодичность.

  • Сумма арифметической прогрессии: (a₁ + aₖ)·k / 2.
  • Сумма первых m нечётных чисел равна m².
  • Сумму значений F на отрезке считают циклом по таблице.
  • Для больших n ищите шаг и повторяющийся блок.
  • В Python большие целые точны; избегайте float для точных ответов.
  • Если ответ просят по модулю, берите остаток на каждом шаге.
S = (a₁ + aₖ)·k / 21 + 3 + … + (2m−1) = m²

Несколько функций

Взаимная рекурсия: F вызывает G, G вызывает F. Значения вычисляют парами, а таблицу заполняют одновременно для обеих функций.

  • База задаётся для каждой функции отдельно.
  • Храните пару (F(n), G(n)) или два массива.
  • При шаге назад начинайте с базы и идите вверх.
  • При шаге вперёд идите от границы вниз.
  • В Python кортежное присваивание F, G = …, … вычисляет правую часть до записи.
(F(n), G(n)) = Φ(F(n−1), G(n−1))F(n) = G(n−1), G(n) = G(n−2) + 1

Количество n по условию

Иногда нужно не одно значение, а число аргументов, для которых F(n) обладает свойством: является квадратом, содержит заданную цифру или кратно числу. Тогда F(n) считают для каждого n из диапазона и проверяют свойство.

  • Определите границы диапазона: включительно или нет.
  • Заполните таблицу F(n) до верхней границы.
  • Свойство проверяйте после вычисления значения.
  • Полный квадрат: x ≥ 0 и int(x**0.5)**2 == x.
  • Наличие цифры: str(x).count('7') > 0.
  • Кратность: x % m == 0.
  • Разные n могут давать одно и то же F(n); считают именно n.
количество = |{n ∈ [a; b] : P(F(n))}|

Обратная задача и проверка

Иногда требуется найти параметр x или границу, при которых выполняется условие. Сначала упростите выражение, затем переберите x в разумных пределах и проверьте ответ.

  • Выразите разность F(a) − F(b) через несколько шагов рекурсии.
  • Для линейного x получается уравнение A + B·x = C.
  • Диапазон перебора берите из условия; при отсутствии — от −10⁵ до 10⁵.
  • Проверьте, что x целый и входит в допустимую область.
  • Убедитесь, что рекурсия завершается и не уходит в бесконечность.
  • Сверьте ответ с ключом на малых аналогах задачи.
F(a) − F(b) = A + B·xx = (C − A) / B

Разбор примера

Учебный пример: F(10) и F(9) при шаге n−2

Функция задана так: F(n) = 2 при n ≤ 2, F(n) = n·F(n−2) при n > 2. Нужно найти F(10) − F(9).

Значения функции для n = 1…10
n12345678910
F(n)226830482103841 8903 840
  1. База: F(1) = F(2) = 2.
  2. Чётная цепочка: F(4) = 4·F(2) = 8, F(6) = 6·F(4) = 48, F(8) = 8·F(6) = 384, F(10) = 10·F(8) = 3 840.
  3. Нечётная цепочка: F(3) = 3·F(1) = 6, F(5) = 5·F(3) = 30, F(7) = 7·F(5) = 210, F(9) = 9·F(7) = 1 890.
  4. Цепочки не пересекаются: шаг n−2 сохраняет чётность аргумента.
  5. Считаем разность: 3 840 − 1 890 = 1 950.

Ответ1 950.

Способы решения

Выберите метод под формулировку

Методы собраны по решениям задания 16 из базы Kompege. Начните с того, что именно нужно найти в условии.

01

когда n небольшое

Прямая подстановка

Когда использовать: n измеряется десятками, а формула содержит один или два вызова — быстрее раскрыть вручную, чем писать программу.

  1. Выпишите базовые значения.
  2. Раскрывайте вызовы, пока не дойдёте до базы.
  3. Подставляйте значения снизу вверх.
  4. Для суммы или произведения группируйте одинаковые шаги.
  5. Проверьте количество шагов и знаки.

Пример

F(n) = 4 при n ≤ 16; F(n) = n·F(n−2) при n > 16. Найдём F(24).

def f(n):
    return 4 if n <= 16 else n * f(n - 2)

print(f(24))  # 760320

Ответ760 320: 24·22·20·18·4.

Задача № 10929 (база Kompege).

02

когда n большое

Таблица значений снизу вверх

Когда использовать: n — сотни или тысячи, рекурсия линейная или содержит немного ветвей. Таблица убирает повторные вызовы и переполнение стека.

  1. Определите базу и правую границу.
  2. Создайте массив или словарь.
  3. Заполните базовые значения.
  4. Идите по n в нужном направлении и применяйте формулу.
  5. Возьмите готовое значение или разность значений.

Пример

F(n) = n при n ≤ 6; F(n) = 2n + 3 + F(n−1) при n > 6. Найдём F(6188) − F(6185).

f = {n: n for n in range(1, 7)}
for n in range(7, 6189):
    f[n] = 2 * n + 3 + f[n - 1]

print(f[6188] - f[6185])  # 37131
print(6 * 6188 + 3)       # 37131

Ответ37 131: разность трёх соседних шагов даёт 6n + 3.

Задача № 11235 (база Kompege).

03

когда подзадачи повторяются

Мемоизация через lru_cache

Когда использовать: Ветвление снова и снова вызывает одни и те же аргументы, а вручную строить таблицу неудобно.

  1. Импортируйте lru_cache из functools.
  2. Поставьте декоратор перед функцией.
  3. Опишите базу и шаг в естественном виде.
  4. При необходимости прогрейте кэш циклом.
  5. Сравните результат с таблицей на малых n.

Пример

F(n) = n при n ≤ 3; F(n) = n(n−1) + F(n−1) + F(n−2) при n > 3. Найдём F(3333) − F(3332) − F(3331).

from functools import lru_cache

@lru_cache(None)
def f(n):
    if n <= 3:
        return n
    return n * (n - 1) + f(n - 1) + f(n - 2)

for i in range(1, 3334):
    f(i)

print(f(3333) - f(3332) - f(3331))  # 11105556

Ответ11 105 556; разность равна 3333·3332.

Задача № 13952 (база Kompege).

04

когда база при n ≥ N

Рекурсия вперёд

Когда использовать: Шаг увеличивает аргумент: n+1, n+2 или 2n, а база задана при больших n.

  1. Найдите границу базы.
  2. Заполняйте значения от границы вниз.
  3. Для n+2 сохраняйте чётность аргумента.
  4. Не вызывайте функцию «в лоб»: глубина может превысить 1000.
  5. Проверьте значения рядом с границей.

Пример

F(n) = n при n > 18; F(n) = 3·F(n+1) + n + 8 при n ≤ 18. Найдём F(9).

from functools import lru_cache

@lru_cache(None)
def f(n):
    if n > 18:
        return n
    return 3 * f(n + 1) + n + 8

print(f(9))  # 1874798

Ответ1 874 798.

Задача № 273 (база Kompege).

05

когда есть n % 2 или n % 3

Ветвление по чётности и делимости

Когда использовать: Формула зависит от остатка или от чётности предыдущего значения.

  1. Выпишите условия и порядок ветвей.
  2. Определите базу для каждого остатка.
  3. Помните: шаг n−2 сохраняет чётность, шаг n−1 меняет.
  4. Считайте по таблице или с кэшем.
  5. Проверьте обе ветви на малых n.

Пример

F(n) = 1 при n ≤ 1; F(n) = n·F(n−1) при чётных n > 1; F(n) = n + F(n−2) при нечётных n > 1. Найдём F(84).

from functools import lru_cache

@lru_cache(None)
def f(n):
    if n <= 1:
        return 1
    if n % 2 == 0:
        return n * f(n - 1)
    return n + f(n - 2)

print(f(84))  # 148176

Ответ148 176.

Задача № 598 (база Kompege).

06

когда заданы F(n) и G(n)

Две взаимно рекурсивные функции

Когда использовать: F ссылается на G, а G — на F. Значения нужно считать одновременно, парой.

  1. Выпишите базу для F и для G.
  2. Храните пару значений или два массива.
  3. Идите от n = 1 вверх, если шаг назад.
  4. Используйте значения предыдущего шага.
  5. Проверьте обе функции на малых n.

Пример

F(1) = G(1) = 1; F(n) = F(n−1) − 2·G(n−1); G(n) = F(n−1) + 2·G(n−1). Найдём G(21).

n = 21
F, G = 1, 1          # n = 1
for i in range(2, n + 1):
    F, G = F - 2 * G, F + 2 * G

print(G)  # 802165

Ответ802 165.

Задача № 591 (база Kompege).

07

когда спрашивают «сколько раз»

Количество вызовов

Когда использовать: Нужно не значение функции, а число её вызовов или выполнений.

  1. Определите, считается ли корневой вызов.
  2. Для базы возьмите 1 — сам вызов.
  3. Для шага сложите 1 и количество вызовов детей.
  4. Решите рекуррентность по таблице.
  5. Проверьте на n = 3, 4, 5 вручную.

Пример

F(n) = 2 при n ≤ 2; F(n) = F(n−1) − 2·F(n−2) при n > 2. Сколько вызовов при F(57)?

from functools import lru_cache

@lru_cache(None)
def calls(n):
    if n <= 2:
        return 1
    return 1 + calls(n - 1) + calls(n - 2)

from functools import lru_cache

когда процедура печатает числа

Сумма выведенных чисел

Когда использовать: Нужно найти сумму чисел, которые выведет рекурсивная процедура.

  1. Запишите, какие числа печатает текущий вызов.
  2. Проверьте условие печати отдельно.
  3. Сложите числа текущего вызова с суммами детей.
  4. Для базы учтите только гарантированную печать.
  5. Проверьте на n = 2 и n = 3.

Пример

Процедура печатает 2n+1; при n > 1 печатает ещё 3n−8 и вызывает F(n−1), F(n−4). Найдём сумму для F(50).

from functools import lru_cache

@lru_cache(None)
def total(n):
    s = 2 * n + 1
    if n > 1:
        s += (3 * n - 8) + total(n - 1) + total(n - 4)
    return s

print(total(50))  # 170480034

когда нужна сумма F(k)

Сумма значений на отрезке

Когда использовать: Условие просит сумму значений функции для k из диапазона, а не одно значение.

  1. Заполните таблицу значений до правой границы.
  2. Для каждого k из диапазона примените формулу.
  3. Сложите значения.
  4. Не включайте лишние границы.
  5. Проверьте количество слагаемых: b − a + 1.

Пример

F(n) = n + 3 при n ≤ 3; дальше F(n) = F(n−2) + n или +2n в зависимости от чётности F(n−1). Найдите сумму F(40)…F(50).

from functools import lru_cache

@lru_cache(None)
def f(n):
    if n <= 3:
        return n + 3
    if f(n - 1) % 2 == 0:
        return f(n - 2) + n
    return f(n - 2) + 2 * n

print(sum(f(n) for n in range(40, 51)))  # 8508

Ответ8 508.

когда нужно найти x

Обратная задача: параметр x

Когда использовать: Известно значение выражения с параметром x, и нужно найти сам параметр.

F(n) = n при n ≥ 3000; F(n) = n + x + F(n+2) при n < 3000. Найдите целое x, если F(2984) − F(2988) = 5916.

def f(n, x):
    if n >= 3000:
        return n
    return n + x + f(n + 2, x)

for x in range(-100, 100):
    if f(2984, x) - f(2988, x) == 5916:
        print(x)  # -27
        break

13

когда нужен перебор аргументов

Количество n по условию

Когда использовать: Спрашивают, сколько n из диапазона дают нужное свойство значения функции.

  1. Определите диапазон и включение границ.
  2. Заполните таблицу F(n) до верхней границы.
  3. Для каждого n проверьте свойство.
  4. Увеличьте счётчик при выполнении условия.
  5. Проверьте края диапазона отдельно.

Пример

F(n) = G(n−1); G(n) = n при n < 10; G(n) = G(n−2) + 1 при n ≥ 10. Сколько n на отрезке [1; 100] дают полный квадрат?

from functools import lru_cache

@lru_cache(None)
def G(n):
    if n < 10:
        return n
    return G(n - 2) + 1

def F(n):
    return G(n - 1)

count = 0
for n in range(1, 101):
    x = F(n)
    if x > 0 and int(x ** 0.5) ** 2 == x:
        count += 1

print(count)  # 12

Ответ12 значений n.
