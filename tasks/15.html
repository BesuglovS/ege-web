Логические операции

Формула задания — это высказывание о числе x. Сначала расставьте операции по приоритету: отрицание, конъюнкция, дизъюнкция, импликация, эквивалентность. Скобки важнее приоритета.

  • ¬A — «не A»; A ∧ B — «A и B»; A ∨ B — «A или B», причём «или» неисключающее.
  • A → B — «если A, то B»; A ≡ B — «A тогда и только тогда, когда B».
  • Импликация ложна только в одном случае: A истинно, B ложно.
  • Эквивалентность истинна, когда значения A и B совпадают.
  • Законы де Моргана помогают убрать отрицание перед скобкой.
A → B = ¬A ∨ BA ≡ B = (A ∧ B) ∨ (¬A ∧ ¬B)¬(A ∧ B) = ¬A ∨ ¬B¬(A ∨ B) = ¬A ∧ ¬B

Импликация и её отрицание

Почти все задачи сводятся к вопросу, где импликация может стать ложной. Это происходит только на множестве A \ B: там A истинно, а B ложно. Поэтому отрицание импликации — это A ∧ ¬B.

  • A → B истинна на всём, кроме A \ B.
  • Если A — отрезок, а B — условие на x, ищите часть A, где B не выполняется.
  • Цепочка A → B → C раскрывается слева направо: ¬A ∨ ¬B ∨ C.
  • «Тождественно истинно» означает, что запрещённых точек нет.
  • «Тождественно ложно» означает, что истинных точек нет.
A → B = ¬A ∨ B¬(A → B) = A ∧ ¬BA → (B → C) = ¬A ∨ ¬B ∨ C

Кванторы и формулировки

В условии почти всегда написано «при любом x» или «для всех x, y». Это квантор всеобщности. Он требует, чтобы формула была истинна в каждой точке допустимой области, а не в одной удачной.

  • ∀x P(x) — P верно для всех x из области.
  • ∃x P(x) — существует хотя бы одно x, где P верно.
  • Отрицание ∀x P(x) — это ∃x ¬P(x), а не ∀x ¬P(x).
  • «Тождественно истинно» = ∀x P(x); «тождественно ложно» = ∀x ¬P(x).
  • «Не тождественно истинно» = ∃x ¬P(x): достаточно одного контрпримера.
  • Область x важна: натуральные, целые, неотрицательные и положительные числа дают разные ответы.
¬∀x P(x) = ∃x ¬P(x)¬∃x P(x) = ∀x ¬P(x)

Множества и числовая прямая

Условие x ∈ A — это принадлежность множеству. Отрезки, интервалы и полуинтервалы — частные случаи множеств на числовой прямой. Рисунок почти всегда быстрее формул.

  • A ∪ B — объединение; A ∩ B — пересечение; A \ B — разность; ¬A — дополнение.
  • [a; b] включает оба конца, (a; b) не включает, [a; b) включает только a.
  • На прямой удобно отмечать границы и штриховать запрещённые и обязательные участки.
  • Для дискретных множеств (целые числа, делители) рисуйте не прямую, а список элементов.
  • Пустое множество допустимо, если в условии нет запрета.
x ∈ A ∪ B ⇔ x ∈ A ∨ x ∈ Bx ∈ A ∩ B ⇔ x ∈ A ∧ x ∈ Bx ∈ A \ B ⇔ x ∈ A ∧ x ∉ B

Импликация как включение

Для множеств x ∈ A → x ∈ B означает A ⊆ B. Это главный перевод условий про отрезки и множества. Если A не должно выходить за B, то A — подмножество B; если A обязано покрыть разность, то B \ C ⊆ A.

  • A ⊆ B: каждая точка A лежит в B.
  • A → B ложно ровно на A \ B, поэтому нужно сделать A \ B пустым.
  • Если A неизвестно, а B и C даны, условие часто превращается в B \ C ⊆ A.
  • Для «наибольшей длины A» ищите максимальное подмножество, не нарушающее запрет.
  • Для «наименьшей длины A» ищите минимальное покрытие обязательной части.
(x ∈ A → x ∈ B) ⇔ A ⊆ BA → B нарушается ⇔ A \ B ≠ ∅

Отрезки: длина и целые точки

Длина отрезка [a; b] равна b − a, а количество целых точек — b − a + 1. Для полуинтервала и интервала формулы отличаются на единицу, поэтому проверяйте включение концов.

  • Длина [a; b] = b − a; длина (a; b) = b − a.
  • Целых точек в [a; b]: b − a + 1, если a и b целые.
  • Целых точек в [a; b): b − a; в (a; b]: b − a; в (a; b): b − a − 1.
  • Если концы нецелые, считайте целые точки отдельно или округляйте аккуратно.
  • Минимальная длина A, покрывающего промежуток, равна его длине; максимальная — длине разрешённой области.
  • Не путайте длину и количество целых точек: ответ может отличаться на 1.
|[a; b]| = b − aN([a; b]) = b − a + 1N([a; b)) = b − a

Делимость и кратные

ДЕЛ(x, m) означает, что x кратно m. Множество таких x — {0, m, 2m, …}. Пересечение условий делимости — это кратность НОК, а не произведению.

  • ДЕЛ(x, m) ⇔ x mod m = 0.
  • ДЕЛ(x, a) ∧ ДЕЛ(x, b) ⇔ ДЕЛ(x, НОК(a, b)).
  • ДЕЛ(x, a) ∨ ДЕЛ(x, b) — объединение двух множеств кратных; НОК здесь не заменяет дизъюнкцию.
  • A → B для делимости: все кратные A должны попасть в B.
  • Наибольшее A обычно делит некоторое НОК; наименьшее A добавляет недостающие множители.
  • Для x = 0 делимость выполнена при любом m; учитывайте область определения.
ДЕЛ(x, m) ⇔ ∃k ∈ ℤ: x = kmДЕЛ(x, a) ∧ ДЕЛ(x, b) ⇔ ДЕЛ(x, НОК(a, b))

НОД и НОК

НОД — наибольший общий делитель, НОК — наименьшее общее кратное. Через разложение на простые множители НОК берёт максимальные степени, а НОД — минимальные.

  • НОК(a, b) = a·b / НОД(a, b).
  • Для взаимно простых a и b НОК(a, b) = a·b.
  • В делимости чаще нужен НОК: он описывает общие кратные.
  • НОД полезен, когда нужно наибольшее A, делящее несколько чисел.
  • Проверяйте, что A натуральное и не превосходит ограничение из условия.
НОК(a, b) = a·b / НОД(a, b)a = 2^α·3^β·5^γ…, b = 2^δ·3^ε·5^ζ…НОД берёт min(α, δ), НОК — max(α, δ)

Поразрядные операции

В задачах с &, |, ^ и ↑ числа удобно переводить в двоичную запись. Операции выполняются независимо в каждом бите, поэтому маску A можно собирать по битам.

  • x & A = 0 — у x и A нет общих единичных битов.
  • x & A ≠ 0 — есть хотя бы один общий единичный бит.
  • x | A — объединение единичных битов; x ^ A — биты, где значения различаются.
  • x ^ A = 0 ⇔ x = A; x ^ A ≠ 0 ⇔ x ≠ A.
  • x & m = m означает, что все единичные биты m есть в x.
  • Поразрядная импликация n ↑ m: в каждом бите n → m, то есть ¬n ∨ m.
  • Для поиска A перебирайте биты или небольшие диапазоны; маска быстро стабилизируется.
x & A = 0 ⇔ нет общих единицx ^ A = 0 ⇔ x = An ↑ m = ¬n ∨ m (по битам)

Условия с двумя переменными

Когда в формуле есть x и y, истинность проверяется для всех пар. Часто формула ложна только на одной линии или в одной точке; тогда достаточно исследовать равенство, а не перебирать весь квадрат.

  • Найдите случаи, когда первое слагаемое ложно: обычно это уравнение.
  • На линии или в точке подставьте выражение и найдите максимум/минимум.
  • Для линейных выражений экстремум достигается в конце отрезка или в целой точке.
  • Для произведения x·y и квадратов проверяйте границы и нули.
  • Если область x, y не ограничена, ищите асимптотику и критические точки.
  • Перебор по x и y допустим, если диапазон небольшой; иначе сокращайте до критических пар.
∀x ∀y P(x, y) — проверить все парыP ложно только при равенстве f(x, y) = C

Остатки и пользовательские предикаты

mod(x, m) — остаток от деления x на m; он периодичен с периодом m. Пользовательские функции (последняя цифра, количество единиц, сумма цифр) тоже часто периодичны или сводятся к конечному перебору.

  • mod(x, m) = r ⇔ x = km + r.
  • Остаток повторяется каждые m чисел: проверяйте один период.
  • Последняя цифра — это x mod 10; первая цифра требует оценки разрядов.
  • Чётность количества единиц в двоичной записи — bin(x).count('1') % 2.
  • Для цифры x перебирайте 0…9; для трёхзначного числа — 100…999.
  • Сначала проверьте, не пусто ли множество решений: тогда подходит и A = 0.
mod(x, m) = r ⇔ x ≡ r (mod m)last_digit(x) = x mod 10

Перебор и проверка

На экзамене перебор на Python — законный способ, если правильно выбрать границы. Проверяйте не только ответ, но и область определения, целочисленность и минимальность/максимальность.

  • Для A перебирайте диапазон с запасом: от 0 или 1 до 1000–10000, если нет ограничения.
  • Для x перебирайте шире, чем границы отрезков, но не бесконечно.
  • Используйте all(...) для «для всех» и any(...) для «существует».
  • Проверяйте обе стороны: найденное A не должно нарушать условие на соседних значениях.
  • Для длины отрезка перебирайте концы, а не все точки, если нужна точность.
  • Сравните ответ с оценкой: длина не больше длины объемлющего отрезка, A не больше ограничения.
  • Перед записью ответа перечитайте, что именно просят: длину, количество, сумму или произведение.
all(P(x) for x in range(...))any(P(x) for x in range(...))

Разбор примера

Учебный пример: кратчайший отрезок A

На числовой прямой даны D = [7; 68] и C = [29; 100]. Найдём наименьшую длину A, при которой формула (x ∈ D) → ((¬(x ∈ C) ∧ ¬(x ∈ A)) → ¬(x ∈ D)) истинна для всех x.

[a; b]включает a и bпроверить оба конца

  1. Раскроем внешнюю импликацию: формула ложна, только если x ∈ D, а внутренняя импликация ложна.
  2. Внутренняя импликация (¬(x ∈ C) ∧ ¬(x ∈ A)) → ¬(x ∈ D) ложна, когда x ∈ D, x ∉ C и x ∉ A.
  3. Значит, все точки D \ C = [7; 29) обязаны лежать в A.
  4. Минимальный отрезок A, покрывающий [7; 29), — это [7; 29] или [7; 29); его длина равна 29 − 7 = 22.
  5. Проверяем: при x ∈ [7; 29) условие x ∈ A выполнено, поэтому внутренняя импликация не может стать ложной.

Ответ22.

Способы решения

Выберите метод под формулировку

Методы собраны по решениям задания 15 из базы Kompege. Начните с того, что именно нужно найти в условии.

01

когда A — отрезок и есть импликации

Отрезки: найти обязательную разность

Когда использовать: В условии даны отрезки и формула с →, а нужно найти наименьшую или наибольшую длину A.

  1. Раскройте импликации по правилу A → B = ¬A ∨ B.
  2. Найдите единственный случай, когда формула ложна: antecedent true, consequent false.
  3. Переведите этот случай в требование «такие x обязаны лежать в A».
  4. Вычислите длину обязательного промежутка или разрешённой области.
  5. Проверьте концы: включение границы может изменить длину на 1.

Пример

D = [7; 68], C = [29; 100], формула (x ∈ D) → ((¬(x ∈ C) ∧ ¬(x ∈ A)) → ¬(x ∈ D)).

# Обязательная часть: D \ C = [7; 29)
print(29 - 7)  # 22

02

когда формула сложная

Отрезки: перебор концов

Когда использовать: Формула содержит несколько отрезков, эквивалентности или отрицания, и вручную легко запутаться.

  1. Обозначьте A = [a1; a2].
  2. Соберите все границы из условия и добавьте по 0,5–1 в обе стороны.
  3. Переберите a1 и a2 по этим точкам.
  4. Проверьте формулу на всех контрольных x: границы, середины, соседние точки.
  5. Выберите минимальную или максимальную подходящую длину.

Пример

P = [15; 40], Q = [21; 63], формула (x ∈ P) → (((x ∈ Q) ∧ ¬(x ∈ A)) → ¬(x ∈ P)).

best = None
for a1 in range(0, 70):
    for a2 in range(a1, 70):
        ok = all(
            (15 <= x <= 40) <= (
                ((21 <= x <= 63) and not (a1 <= x <= a2))
                <= (not (15 <= x <= 40))
            )
            for x in range(0, 70)
        )
        if ok:
            length = a2 - a1
            best = length if best is None else min(best, length)

print(best)  # 19

Ответ19.

03

когда A, P, Q — множества чисел

Множества: включения и запреты

Когда использовать: Нужно найти наибольшее количество элементов A или само множество A.

  1. Переведите каждую импликацию в включение: x ∈ A → x ∈ P означает A ⊆ P.
  2. Переведите отрицание в запрет: x ∈ Q → x ∉ A означает A ∩ Q = ∅.
  3. Соберите разрешённое множество: элементы, которые могут входить в A.
  4. Для максимума возьмите всё разрешённое множество; для минимума — только обязательные элементы.
  5. Проверьте, что все элементы натуральные и удовлетворяют ограничениям.

Пример

P = {2, 4, 6, …, 30}, Q = {1, 4, 7, …, 31}, формула ((x ∈ A) → (x ∈ P)) ∧ ((x ∈ Q) → (x ∉ A)).

P = set(range(2, 31, 2))
Q = {1, 4, 7, 10, 13, 16, 19, 22, 25, 28, 31}
allowed = P - Q
print(len(allowed), sorted(allowed))
# 10 [2, 6, 8, 12, 14, 18, 20, 24, 26, 30]

Ответ10 элементов.

04

когда ищут сумму или произведение

Множества: обязательные элементы

Когда использовать: Нужно не количество, а сумма или произведение элементов A; важно найти минимальный обязательный набор.

  1. Раскройте импликацию: A → (B ∨ C) = ¬A ∨ B ∨ C.
  2. Найдите x, при которых B ложно, а A истинно: только они обязаны попасть в C.
  3. Для минимума суммы или произведения добавляйте только обязательные элементы.
  4. Проверьте, нет ли ограничения «множество непусто» или «элементы натуральные».
  5. Вычислите сумму или произведение и проверьте арифметику.

Пример

S1 = {2, 4, 8, 12, 15}, S2 = {3, 6, 8, 15}, формула (x ∈ S1) → (¬(x ∈ S2) ∨ (x ∈ A)).

S1 = {2, 4, 8, 12, 15}
S2 = {3, 6, 8, 15}
need = S1 & S2
prod = 1
for x in need:
    prod *= x

print(sorted(need), prod)  # [8, 15] 120

05

когда ДЕЛ(x, a) и ДЕЛ(x, b)

Делимость: НОК и общие кратные

Когда использовать: В формуле несколько условий делимости, и нужно найти наибольшее или наименьшее A.

  1. Замените ДЕЛ(x, m) на «x кратно m».
  2. Соедините условия через НОК: ДЕЛ(x, a) ∧ ДЕЛ(x, b) = ДЕЛ(x, НОК(a, b)).
  3. Раскройте импликацию и найдите, какие x обязаны быть кратны A.
  4. Для наибольшего A возьмите НОК или его делитель; для наименьшего добавьте недостающие простые множители.
  5. Проверьте A на нескольких кратных и на числе 0, если оно входит в область.

Пример

ДЕЛ(x, 120) → (¬ДЕЛ(x, A) → ¬ДЕЛ(x, 512)). Нужно наибольшее A.

from math import gcd
a, b = 120, 512
print(a * b // gcd(a, b))  # 7680

06

когда A входит в ДЕЛ(x, A)

07

когда есть x & A

Поразрядная конъюнкция &

Когда использовать: В условии встречаются x & m = 0, x & m ≠ 0 или x & m = m.

  1. Переведите числа в двоичную запись и выровняйте по длине.
  2. x & A = 0 означает: ни один единичный бит A не должен стоять в x.
  3. x & A ≠ 0 означает: хотя бы один единичный бит A должен быть в x.
  4. Соберите запрещённые и разрешённые биты из условий.
  5. Для проверки переберите A и x в небольших диапазонах; маска быстро находится.

Пример

(x & 30 ≠ 4) ∨ ((x & 35 = 1) → (x & A = 0)). Нужно наибольшее A.

def f(x, A):
    return (x & 30 != 4) or ((x & 35 == 1) <= (x & A == 0))

ans = max(A for A in range(1, 1000)
          if all(f(x, A) for x in range(1, 1000)))
print(ans)  # 58

08

когда есть x ⊕ A

XOR и битовые маски

Когда использовать: В условии есть исключающее ИЛИ, и нужно найти A.

  1. Запомните: x ⊕ A = 0 тогда и только тогда, когда x = A.
  2. x ⊕ m = 0 сразу задаёт x = m; подставьте это значение в остальные части.
  3. Если x ⊕ A ≠ 0, то x ≠ A; используйте это как запрет.
  4. Для выражений с & и ⊕ перебирайте биты или небольшие A.
  5. Проверьте найденное A на всех x из условия.

Пример

((x ⊕ 52 ≠ 0) ∧ (x ⊕ 48 = 0)) → ¬(x ⊕ A ≠ 0). Нужно наименьшее A.

def f(x, A):
    return ((x ^ 52 != 0) and (x ^ 48 == 0)) <= ((x ^ A) == 0)

print(min(A for A in range(100)
          if all(f(x, A) for x in range(100))))  # 48

09

когда x и y в одном условии

Две переменные: равенство и критические пары

Когда использовать: Формула должна быть истинна для всех x и y, но ложна только при одном равенстве.

  1. Найдите, когда первое слагаемое ложно: обычно это уравнение.
  2. Решите уравнение в целых числах или выразите y через x.
  3. Подставьте решения во второе слагаемое.
  4. Найдите максимум или минимум по всем решениям.
  5. Для «A > …» прибавьте 1; для «A < …» вычтите 1.

Пример

(6x + 4y ≠ 34) ∨ ((A > 5x + 3y) ∧ (A > 4y + 15x − 35)). Нужно наименьшее A.

pairs = [(x, y) for x in range(1, 20) for y in range(1, 20)
         if 6*x + 4*y == 34]
need = max(max(5*x + 3*y, 4*y + 15*x - 35) for x, y in pairs)
print(pairs, need + 1)  # [(1, 7), (3, 4), (5, 1)] 45
