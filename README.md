# ЕГЭ по информатике · подготовка по заданиям

Статический сайт для подготовки к ЕГЭ по информатике: карта из 27 заданий, страницы с базовой информацией по каждому заданию и отдельный реестр официальных документов.

Открыть: **`index.html`** (можно двойным щелчком, без сервера).

## Структура сайта

На **3 ноября 2026 года**:

- проекты КИМ ЕГЭ 2027 опубликованы ФИПИ **28.08.2026**, общественное обсуждение завершилось **30.09.2026**;

## Как обновить

1. Заменить или добавить файлы в `Исходники/`.
2. При необходимости поправить список `DOCS` и `ARCHIVE` в `build_site.py`.
3. Для страниц заданий поправить `content_tasks.py`.
4. Пересобрать сайт:

```powershell
python build_site.py
```

Скрипт заново посчитает размеры, страницы, SHA-256 и создаст `index.html`, `documents.html`, `tasks/index.html`, страницы 27 заданий и `Исходники/manifest.json`.

Для локального просмотра через HTTP:

```powershell
python -m http.server 8765
```

и открыть <http://127.0.0.1:8765/>.

## Деплой

Сайт собирается и выкладывается скриптом `deploy.ps1`:

```powershell
.\deploy.ps1
```

По умолчанию скрипт:

1. запускает `python build_site.py`;
2. проверяет наличие `index.html`, `documents.html` и `tasks/index.html`;
3. создаёт `version.json` с меткой деплоя;
4. упаковывает проект в `tar.gz`, исключая `.git`, `.env`, `deploy.ps1`, `__pycache__` и служебные файлы;
5. загружает архив на сервер по SSH и распаковывает его в `/var/www/ege.nayanovaacademy.ru/public`;
6. выполняет smoke-check главной страницы.

Дополнительные режимы:

```powershell
.\deploy.ps1 -DryRun     # показать команды без выполнения
.\deploy.ps1 -SkipBuild  # не пересобирать сайт, выложить текущие файлы
```

Параметры подключения хранятся в локальном `.env` (он исключён из git и из архива):

```text
DEPLOY_SSH_HOST=...
DEPLOY_SSH_PORT=22
DEPLOY_SSH_USER=deploy
DEPLOY_SSH_KEY=../ssh-deploy.key
DEPLOY_REMOTE_PATH=/var/www/ege.nayanovaacademy.ru/public
SITE_URL=https://ege.nayanovaacademy.ru/
```
