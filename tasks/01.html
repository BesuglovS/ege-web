Теория

Что нужно знать

Задание 1 проверяет умение читать одну и ту же схему дорог в двух видах — графом и таблицей. В 2027 году формулировка не менялась: 1 первичный балл, раздел «Цифровая грамотность».

Минимум для задания 1

  • считать степень вершины по графу и по таблице
  • сопоставлять буквы и номера пунктов
  • читать симметричную таблицу
  • складывать и умножать длины дорог
  • находить кратчайший путь
  • переводить километры в метры
  • проверять порядок чисел в ответе

Граф и таблица

В задании одна и та же схема дорог дана двумя способами. На графе вершины обозначены буквами, а в таблице — номерами П1, П2 и т. д. Нумерация может быть независимой от букв.

  • Вершины — населённые пункты, рёбра — дороги.
  • Число в клетке — длина дороги; пустая клетка или «—» означает, что дороги нет.
  • В вариантах со звёздочкой «*» означает наличие дороги без указания длины.
  • Таблица симметрична: клетка (П2, П3) равна клетке (П3, П2).

Степени вершин

Степень вершины — количество дорог, которые из неё выходят. Это главный признак для сопоставления графа и таблицы.

Как сопоставить таблицу и граф

Сначала ищите вершины, которые нельзя перепутать, затем уточняйте соответствие по соседям.

  • Посчитайте степени всех вершин на графе.
  • Посчитайте степени всех пунктов по таблице.
  • Сопоставьте уникальные степени.
  • Для совпадающих степеней сравните соседей: к каким вершинам они подключены.
  • В конце проверьте все рёбра, а не только те, которые понадобились для ответа.

Пути и маршруты

В разных формулировках могут просить длину пути, длину маршрута, кратчайший путь или наибольший простой путь.

  • Длина маршрута — сумма весов последовательных рёбер.
  • Простой путь не повторяет вершины.
  • Кратчайший путь — минимальная сумма весов.
  • Наибольший простой путь в небольшом графе ищут перебором.
  • Количество путей в ориентированном графе считают динамикой.

Кратчайший путь

Если все длины неотрицательны, работают алгоритм Дейкстры или динамика по вершинам. Вручную удобно вести таблицу расстояний.

Суммы, произведения и единицы

После сопоставления нужная длина находится на пересечении строки и столбца. Дальше выполняйте именно ту операцию, которая написана в условии.

  • Сумма: сложите длины нужных дорог.
  • Произведение: перемножьте длины.
  • Минимум/максимум: выберите подходящее ребро.
  • Проверьте единицы: километры, метры, мили.
  • Не перепутайте порядок двух чисел в ответе.

Если степени совпали

Одинаковых степеней может быть несколько. Тогда смотрите не только на число дорог, но и на то, с какими вершинами они соединяют.

  • Вершина степени 1 — лист; ищите её соседа.
  • Вершина степени 2 соединяет два конкретных пункта.
  • Если вручную сопоставить не удаётся, используйте перебор перестановок.
  • Проверяйте, не пропущена ли одна дорога в таблице.

Формат ответа

В задании 1 ответ всегда короткий, но ошибки в формате стоят балла.

  • Целое число — без единиц измерения и пояснений.
  • Два числа — в порядке, указанном в условии.
  • Если просят «без пробелов и разделителей», пишите слитно.
  • Проверьте, не нужно ли перевести километры в метры.

Разбор примера

Учебный пример: граф и таблица

Сопоставим номера пунктов с буквами и найдём кратчайший путь из A в E.

Таблица к графу: на пересечении строки и столбца — длина дороги
П1П2П3П4П5П6
П1—4————
П24—37——
П3—3—256
П4—72—8—
П5——58——
П6——6———
  1. Степени на графе: A — 1, B — 3, C — 4, D — 3, E — 2, F — 1.
  2. Степени в таблице: П1 — 1, П2 — 3, П3 — 4, П4 — 3, П5 — 2, П6 — 1.
  3. П3 — единственная вершина степени 4, значит П3 = C. П5 — единственная степени 2, значит П5 = E.
  4. П1 и П6 имеют степень 1: П1 связана с П2 степени 3, П6 — с П3 степени 4, поэтому П1 = A, П6 = F.
  5. Для П2 и П4 степени 3: П2 связана с П1 (A), П4 — с П5 (E), значит П2 = B, П4 = D.

ОтветП1 = A, П2 = B, П3 = C, П4 = D, П5 = E, П6 = F. Кратчайший путь A → E: A–B–C–E = 4 + 3 + 5 = 12.

Способы решения

Выберите метод под формулировку

Методы собраны по решениям задания 1 из базы Kompege. Начните с того, что именно нужно найти в условии.

01

когда таблица и граф независимы

Сопоставление по степеням

Когда использовать: Нужно определить, какой номер пункта соответствует букве на графе.

  1. Посчитайте степени всех вершин на графе.
  2. Посчитайте степени всех пунктов по таблице.
  3. Сопоставьте уникальные степени.
  4. Для одинаковых степеней сравните соседей.
  5. Проверьте все рёбра и только потом записывайте ответ.

Пример

В учебном примере П3 — единственная вершина степени 4, поэтому П3 = C. П5 — единственная степени 2, поэтому П5 = E. Остались П1/П6 степени 1: П1 связана с П2 степени 3, П6 — с П3 степени 4, значит П1 = A, П6 = F. Для П2/П4: П2 связана с П1 (A), П4 — с П5 (E), значит П2 = B, П4 = D.

ОтветП1 = A, П2 = B, П3 = C, П4 = D, П5 = E, П6 = F.

По мотивам задачи № 11639 (база Kompege).

02

когда нужны конкретные дороги

Сумма, произведение и выбор ребра

Когда использовать: После сопоставления просят сумму, произведение, минимум или максимум длин.

  1. Найдите нужную пару пунктов в таблице.
  2. Прочитайте число на пересечении строки и столбца.
  3. Проверьте, что это именно та дорога.
  4. Выполните сумму или произведение.
  5. Переведите единицы, если это требуется.

Пример

В учебном примере B → D = 7, C → E = 5. Сумма = 7 + 5 = 12, произведение = 7 × 5 = 35. Если спросят минимальную дорогу из A, смотрим A–B = 4 и A–C = 10: минимум 4.

ОтветСумма 12, произведение 35, минимум из A — 4.

По мотивам задач № 11639 и № 12455.

03

когда есть слово «кратчайший»

Кратчайший путь

Когда использовать: Нужно найти минимальную длину пути или сам маршрут.

  1. Сопоставьте вершины и таблицу.
  2. Начните с расстояния 0 в стартовой вершине, остальные считайте бесконечными.
  3. Для каждого ребра проверяйте, можно ли добраться до вершины короче через текущую.
  4. Выберите вершину с минимальным расстоянием и продолжайте.
  5. Восстановите маршрут по предыдущим вершинам.

Пример

Из A в E: A–B–C–E = 4 + 3 + 5 = 12; A–B–D–E = 4 + 7 + 8 = 19; A–B–C–D–E = 4 + 3 + 2 + 8 = 17. Минимум — 12.

Ответ12.

По мотивам задачи № 9891.

04

когда маршрут уже назван

Длина заданного маршрута

Когда использовать: В условии дана последовательность пунктов, например ABDGECA.

  1. Разбейте маршрут на последовательные пары: AB, BD, DG, …
  2. Для каждой пары найдите длину дороги.
  3. Убедитесь, что все дороги существуют.
  4. Сложите длины.
  5. Проверьте единицы и порядок.

Пример

Маршрут A–B–D–E: A–B = 4, B–D = 7, D–E = 8. Сумма = 4 + 7 + 8 = 19.

Ответ19.

По мотивам задачи № 17081.

05

когда степени совпадают

Перебор перестановок

Когда использовать: Вершин много, степени повторяются, вручную сопоставлять долго.

  1. Запишите таблицу как список соседей для каждого номера.
  2. Запишите все рёбра графа.
  3. Переберите все перестановки букв.
  4. Для каждой перестановки проверьте все рёбра.
  5. Выведите подходящее соответствие.

Пример

Шаблон для учебного примера. В реальной задаче замените table и edges на свои данные.

from itertools import permutations

table = ["2", "1 3 4", "2 4 5 6", "2 3 5", "3 4", "3"]
edges = ["AB", "BC", "BD", "CD", "CE", "CF", "DE"]

for p in permutations("ABCDEF"):
    num = {letter: str(i + 1) for i, letter in enumerate(p)}
    ok = all(
        num[b] in table[int(num[a]) - 1] and num[a] in table[int(num[b]) - 1]
        for a, b in edges
    )
    if ok:
        print(p)

ОтветДля этой таблицы подходит P1=A, P2=B, P3=C, P4=D, P5=E, P6=F.

По мотивам задач № 16248 и № 12455; у № 16248 есть видеоразбор.

06

когда задача не похожа на шаблон

Нестандартные формулировки

Когда использовать: Встречаются наибольший путь, количество путей, пропущенная дорога или проверка на плоскости.

  • Наибольший простой путь: перебирайте пути без повторения вершин; пример — задача № 13973, ответ 76.
  • Количество путей: считайте динамику по ориентированным рёбрам, как в задачах на графы.
  • Одна дорога не отмечена: сопоставьте всё остальное и найдите единственное возможное ребро.
  • Проверка на плоскости: используйте неравенство треугольника; пример — задача № 14347.

По мотивам задач № 13973, № 14347 и № 12642.

Типичные ошибки

  • номера строк и столбцов путают с буквами вершин
  • таблицу и схему считают независимыми
  • в сумму попадают лишние рёбра
  • теряется вес отдельного ребра
